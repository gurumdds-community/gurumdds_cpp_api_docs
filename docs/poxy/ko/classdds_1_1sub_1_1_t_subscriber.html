dds::sub:: Subscriber 클래스

#include <gurumdds/cpp/sub/Subscriber.hpp>

DataReader를 소유하고 구독 기본값을 구성합니다.

연결된 DomainParticipant의 domain에 있는 Topic에 대해 이 Subscriber를 통해 DataReader를 생성합니다.

template <typename DELEGATE>
void dds::sub::TSubscriber::notify_datareaders()

이 Subscriber의 DataReader들을 위한 데이터 사용 가능한 callback 요청

예외
dds::core::Exception C 라이브러리가 오류를 반환했습니다.

기본 구현 객체는 요청을 네이티브 Subscriber에 전달합니다. 네이티브 Subscriber는 history에 레코드가 있고 데이터 도착 callback이 등록된 각 DataReader에 대해 on_data_available() 호출을 예약합니다. Subscriber의 on_data_on_readers() callback에서 이 연산을 호출하면 처리를 개별 DataReader의 callback으로 넘길 수 있습니다.
