모듈

모듈 Core
DDS 공통 타입과 서비스입니다. 시간 간격에는 duration을, 타임스탬프에는 time을, 이벤트를 기다릴 때는 condition을 사용합니다.
모듈 Domain
DomainParticipant와 원격 participant discovery를 다룹니다. DomainParticipant는 DDS domain에서 자신이 생성한 Topic, Publisher, Subscriber를 소유합니다.
모듈 Publication
Publisher, DataWriter, 발행 상태를 다룹니다. Topic에 연결된 DataWriter를 만들어 데이터를 발행하거나 instance의 수명 주기를 갱신합니다.
모듈 Subscription
Subscriber, DataReader, sample 선택, 수신 데이터를 다룹니다. DataReader에서 sample을 읽거나 가져온 다음, 상태와 메타데이터를 확인합니다.
모듈 Topic
데이터 타입을 지정한 Topic, Topic 설명, content filter를 다룹니다. DataWriter와 DataReader에 같은 Topic 이름과 호환되는 타입을 지정합니다.
