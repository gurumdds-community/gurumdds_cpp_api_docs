DataWriter는 한 Topic 타입의 sample을 발행합니다. 같은 DomainParticipant에 속한 Publisher와 Topic으로 만드세요. 실시간으로 주고받는 예제에서는 호환되는 DataReader가 매칭된 뒤 첫 sample을 보냅니다.

Publisher 의 publisher와 Topic과 keyed type 의 Topic<Hello::Msg> 타입인 topic을 사용합니다. 템플릿 인자 Hello::Msg는 DataWriter가 write()에서 받는 C++ 타입입니다.

DataWriter 생성

dds::pub::DataWriter<Hello::Msg> writer(publisher, topic);

write()를 호출하기 전에 key와 payload를 채우세요. Key로 instance를 식별하고 이후 연산에 handle이 필요하면 등록하세요. 첫 쓰기 전에 제한 시간 동안 매칭을 기다리는 방법은 Matching을 확인한 뒤 발행하기 에 있습니다.

Keyed 예제는 아래 코드에 앞서 message라는 Hello::Msg에 userId 7과 전송할 문자열을 채웁니다. writer.write(message)로 쓰면 DataWriter가 key로 instance를 찾습니다. 이후 쓰기나 수명 주기 연산에 handle을 보관해야 할 때 key를 등록합니다.

keyed instance 등록하기

key를 등록해 DataWriter의 instance handle을 가져옵니다. 이후 같은 key를 다룰 때 이 handle을 재사용할 수 있습니다. key로 lookup_instance()를 호출하거나 handle로 key_value()를 호출할 수 있습니다.

const auto writer_handle = writer.register_instance(message);

require(not writer_handle.is_nil(), "Instance registration failed");

require(writer.lookup_instance(message) == writer_handle, "Writer key lookup failed");



Hello::Msg key{};

writer.key_value(key, writer_handle);

require(key.userId == message.userId, "Writer did not return the expected key");

등록 단계에서 writer_handle을 얻었습니다. 다음 쓰기에는 이 handle과 participant.current_time()을 사용합니다. 수신 쪽에서는 이 timestamp를 SampleInfo에서 읽은 값과 비교할 수 있습니다.

source timestamp를 지정해 쓰기

write()에 instance handle과 source timestamp를 전달합니다. 수신 애플리케이션은 sample 메타데이터에서 timestamp를 확인할 수 있습니다.

const auto sent_at = participant.current_time();

writer.write(message, writer_handle, sent_at);

instance 폐기 및 등록 해제하기

dispose_instance()를 호출해 instance를 폐기 상태로 표시합니다. unregister_instance()를 호출해 DataWriter의 등록을 해제합니다. 예제는 DataWriter에서 해당 key의 등록이 더 이상 조회되지 않는지 확인합니다.

writer.dispose_instance(writer_handle);

Reader 쪽 코드는 Dispose된 instance 감지 에서 확인하세요. 전체 예제는 reader가 dispose를 감지한 뒤 key 등록을 해제합니다.

writer.unregister_instance(writer_handle);

require(writer.lookup_instance(message).is_nil(), "Writer still has a registration for the key");

sample 범위 쓰기

write()에 시작과 끝 반복자를 전달해 범위의 sample을 발행하세요. 예제는 서로 다른 key 두 개를 보내고 DataReader에서 둘 다 확인합니다.

std::array<Hello::Msg, 2> batch{};

batch[0].userId = 8;

batch[1].userId = 9;

for (auto& record : batch)

    record.message = label;



writer.write(batch.begin(), batch.end());

writer.qos()로 Reliability 또는 History를 읽어 요청값과 비교하세요. Publisher 기본값으로 생성했다면 이후 변경되기 전에 기본값을 기록하세요.

DDS acknowledgment 기다리기

Reliable 전달에서는 wait_for_acknowledgments()에 유한한 timeout을 지정하세요. DDS 확인 응답은 수신 미들웨어의 수신을 뜻합니다. 애플리케이션의 처리 완료는 별도 신호로 확인하세요.

writer.wait_for_acknowledgments(Duration::from_millisecs(500));

Writer 두 개의 DDS acknowledgment 대기

Publisher 하나에 reliable Writer 두 개를 만들고, 각각 reliable Reader와 매칭합니다. Topic마다 샘플 하나를 쓴 뒤 Publisher에서 유한한 시간 동안 한 번 대기합니다.

Publisher는 Writer들의 대기에 하나의 타임아웃을 적용합니다. 전체 예제는 각 Reader에서 샘플 하나를 별도로 가져옵니다.

howto::wait_for_readers(first_writer, 1);

howto::wait_for_readers(second_writer, 1);



char message[] = "publisher acknowledgment";

Hello::Msg data{};

data.userId = 7;

data.message = message;

first_writer.write(data);

second_writer.write(data);



publisher.wait_for_acknowledgments(Duration::from_millisecs(1000));

Keyed sample 연산

key를 등록하고 timestamp를 지정해 sample을 발행합니다. instance로 sample을 선택하고 DataWriter 등록을 해제한 뒤 여러 sample의 전달을 확인합니다.

아래 명령으로 프로그램을 빌드하세요. 실행에 성공하면 Keyed sample examples passed를 출력합니다.

cmake --build . --target example_cpp_howto_keyed_samples
완성 코드
#include <array>



#include "demo.hpp"



namespace

{

void use_keyed_samples()

{

    using howto::require;

    using dds::core::policy::Reliability;

    using dds::core::policy::ReaderDataLifecycle;

    using dds::core::policy::WriterDataLifecycle;

    using dds::sub::status::DataState;

    using dds::sub::status::InstanceState;



    dds::domain::DomainParticipant participant(93);

    dds::topic::Topic<Hello::Msg> topic(participant, "HowToKeyed");

    dds::pub::Publisher publisher(participant);

    dds::sub::Subscriber subscriber(participant);

    const auto reliable = Reliability::Reliable(dds::core::Duration::from_millisecs(200));

    auto writer_qos = publisher.default_writer_qos();

    writer_qos << reliable << WriterDataLifecycle(false);

    auto reader_qos = subscriber.default_datareader_qos();

    reader_qos << reliable;

    auto lifecycle = reader_qos.policy<ReaderDataLifecycle>();

    lifecycle.autopurge_disposed_samples_delay(dds::core::Duration::from_millisecs(10000));

    reader_qos << lifecycle;

    dds::pub::DataWriter<Hello::Msg> writer(publisher, topic, writer_qos);

    dds::sub::DataReader<Hello::Msg> reader(subscriber, topic, reader_qos);

    howto::wait_for_readers(writer, 1);



    char label[] = "keyed message";

    Hello::Msg message{};

    message.userId = 7;

    message.message = label;



    // [register_key]

    const auto writer_handle = writer.register_instance(message);

    require(not writer_handle.is_nil(), "Instance registration failed");

    require(writer.lookup_instance(message) == writer_handle, "Writer key lookup failed");



    Hello::Msg key{};

    writer.key_value(key, writer_handle);

    require(key.userId == message.userId, "Writer did not return the expected key");

    // [register_key]



    // [write_timestamp]

    const auto sent_at = participant.current_time();

    writer.write(message, writer_handle, sent_at);

    // [write_timestamp]



    // [receive_metadata]

    howto::wait_until([&reader, &sent_at]() -> bool {

        const auto samples = reader.select().state(DataState::new_data()).read();

        for (const auto& sample : samples)

        {

            if (not sample.info().valid())

                continue;



            const auto timestamp = sample.info().timestamp();

            require(timestamp.sec() == sent_at.sec() and timestamp.nanosec() == sent_at.nanosec(), "Timestamp differs");

            if (sample.data().userId == 7)

                return true;

        }



        return false;

    }, "Timestamped sample did not arrive");

    // [receive_metadata]



    // [select_instance]

    const auto reader_handle = reader.lookup_instance(message);

    require(not reader_handle.is_nil(), "Reader has no handle for this key");

    {

        const auto selected = reader.select().instance(reader_handle).max_samples(1).read();

        require(selected.length() == 1, "Expected one record for the selected instance");

        const auto& sample = *selected.begin();

        require(sample.info().valid() and sample.data().userId == message.userId, "Selected a different instance");

    }

    // [select_instance]



    // [dispose_key]

    writer.dispose_instance(writer_handle);

    // [dispose_key]



    // [receive_dispose]

    howto::wait_until([&reader, &reader_handle]() -> bool {

        const auto samples = reader.take();

        for (const auto& sample : samples)

        {

            const auto& info = sample.info();

            if (info.instance_handle() == reader_handle

                and not info.valid()

                and info.state().instance_state() == InstanceState::not_alive_disposed())

                return true;

        }



        return false;

    }, "The reader did not observe the dispose notification");

    // [receive_dispose]



    // [unregister_key]

    writer.unregister_instance(writer_handle);

    require(writer.lookup_instance(message).is_nil(), "Writer still has a registration for the key");

    // [unregister_key]



    // [write_batch]

    std::array<Hello::Msg, 2> batch{};

    batch[0].userId = 8;

    batch[1].userId = 9;

    for (auto& record : batch)

        record.message = label;



    writer.write(batch.begin(), batch.end());

    // [write_batch]



    bool received_first = false;

    bool received_second = false;

    howto::wait_until([&reader, &received_first, &received_second]() -> bool {

        const auto samples = reader.take();

        for (const auto& sample : samples)

        {

            if (not sample.info().valid())

                continue;



            received_first = received_first or sample.data().userId == 8;

            received_second = received_second or sample.data().userId == 9;

        }



        return received_first and received_second;

    }, "One or more batch samples were missing");

}



void take_by_sample_and_instance_state()

{

    using dds::core::Duration;

    using dds::core::policy::History;

    using dds::core::policy::Reliability;

    using dds::sub::status::DataState;

    using dds::sub::status::InstanceState;

    using dds::sub::status::SampleState;

    using dds::sub::status::ViewState;



    dds::domain::DomainParticipant participant(101);

    dds::topic::Topic<Hello::Msg> topic(participant, "HowToDataState");

    dds::pub::Publisher publisher(participant);

    dds::sub::Subscriber subscriber(participant);

    const auto reliable = Reliability::Reliable(Duration::from_millisecs(200));

    auto writer_qos = publisher.default_writer_qos();

    writer_qos << reliable << History::KeepLast(4);

    auto reader_qos = subscriber.default_datareader_qos();

    reader_qos << reliable << History::KeepLast(4);

    dds::pub::DataWriter<Hello::Msg> writer(publisher, topic, writer_qos);

    dds::sub::DataReader<Hello::Msg> reader(subscriber, topic, reader_qos);

    howto::wait_for_readers(writer, 1);



    char message[] = "sample state example";

    Hello::Msg sample{};

    sample.userId = 7;

    sample.message = message;



    // [data_state_masks]

    const DataState unread_alive(SampleState::not_read(), ViewState::any(), InstanceState::alive());

    const DataState read_alive(SampleState::read(), ViewState::any(), InstanceState::alive());



    writer.write(sample);

    howto::wait_until([&reader, &unread_alive]() -> bool {

        const auto batch = reader.select().state(unread_alive).read();

        return batch.length() == 1 and batch.begin()->info().valid() and batch.begin()->data().userId == 7;

    }, "Key 7 did not arrive as unread data");



    sample.userId = 8;

    writer.write(sample);



    {

        const auto read = reader.select().state(read_alive).take();

        howto::require(read.length() == 1 and read.begin()->info().valid() and read.begin()->data().userId == 7,

            "Expected only the previously read key");

    }



    howto::wait_until([&reader, &unread_alive]() -> bool {

        const auto batch = reader.select().state(unread_alive).take();

        return batch.length() == 1 and batch.begin()->info().valid() and batch.begin()->data().userId == 8;

    }, "Expected only the unread key");

    // [data_state_masks]

    std::cout << "DataState: key 7 was read and key 8 was unread\n";

}



void inspect_sample_ranks()

{

    using dds::core::Duration;

    using dds::core::policy::History;

    using dds::core::policy::ReaderDataLifecycle;

    using dds::core::policy::Reliability;



    dds::domain::DomainParticipant participant(99);

    dds::topic::Topic<Hello::Msg> topic(participant, "HowToRanks");

    dds::pub::Publisher publisher(participant);

    dds::sub::Subscriber subscriber(participant);

    const auto reliable = Reliability::Reliable(Duration::from_millisecs(200));

    auto writer_qos = publisher.default_writer_qos();

    writer_qos << reliable << History::KeepLast(8);

    auto reader_qos = subscriber.default_datareader_qos();

    auto lifecycle = reader_qos.policy<ReaderDataLifecycle>();

    lifecycle.autopurge_disposed_samples_delay(Duration::from_millisecs(10000));

    reader_qos << reliable << History::KeepLast(8) << lifecycle;

    dds::pub::DataWriter<Hello::Msg> writer(publisher, topic, writer_qos);

    dds::sub::DataReader<Hello::Msg> reader(subscriber, topic, reader_qos);

    howto::wait_for_readers(writer, 1);



    // [rank_generations]

    char first[] = "before dispose";

    char second[] = "after dispose";

    Hello::Msg value{};

    value.userId = 42;

    value.message = first;

    const auto handle = writer.register_instance(value);

    writer.write(value, handle);

    howto::wait_until([&reader]() -> bool {

        const auto samples = reader.read();

        return samples.length() == 1 and samples.begin()->info().valid();

    }, "The first generation did not arrive");



    writer.dispose_instance(handle);

    value.message = second;

    writer.write(value, handle);

    // [rank_generations]



    // [print_sample_ranks]

    howto::wait_until([&reader]() -> bool {

        const auto batch = reader.read();

        unsigned int valid_count = 0;

        for (const auto& sample : batch)

            if (sample.info().valid())

                ++valid_count;

        if (valid_count != 2)

            return false;



        std::cout << "payload | sample | generation | absolute generation\n";

        for (const auto& sample : batch)

        {

            if (not sample.info().valid())

                continue;



            const auto rank = sample.info().rank();

            std::cout << sample.data().message << " | " << rank.sample() << " | "

                << rank.generation() << " | " << rank.absolute_generation() << '\n';

        }

        return true;

    }, "Expected two generations in the same read batch");

    // [print_sample_ranks]

}

}



int main()

{

    return howto::run([]() -> void {

        use_keyed_samples();

        take_by_sample_and_instance_state();

        inspect_sample_ranks();

    }, "Keyed sample examples passed");

}
