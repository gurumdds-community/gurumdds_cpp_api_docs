template <typename READER, typename FwdIterator>
uint32_t dds::sub::find(const dds::sub::Subscriber& sub, const std::string& topic_name, FwdIterator begin, uint32_t max_size)

반환값 찾은 요소의 총 수. 최대 max_size는 제공된 반복자로 복사됩니다.

Subscriber에 속하고 topic_name과 일치하는 Topic에 연결된 기존 DataReader를 조회합니다. 해당하는 DataReader가 없으면 빈 컨테이너를 반환합니다. 내장 Subscriber에서 호출하면 built-in Topic의 내장 DataReader<T> Entity에 접근할 수 있습니다.

const dds::core::InstanceHandleSeq dds::sub::matched_publications(const dds::sub::DataReader<T><T>& dr)

같은 Topic에서 QoS가 호환되고 dds::domain::ignore로 무시하지 않은 DataWriter의 handle을 반환합니다. 로컬 handle은 DCPSPublications built-in Topic의 SampleInfo::instance_handle과 같습니다. 미들웨어가 연결 정보를 로컬에 보관하지 않으면 실패할 수 있습니다.

같은 Topic에서 QoS가 호환되고 dds::domain::ignore로 무시하지 않은 DataWriter의 handle을 반환합니다. 로컬 handle은 DCPSPublications built-in Topic의 SampleInfo::instance_handle과 같습니다. 미들웨어가 연결 정보를 로컬에 보관하지 않으면 실패할 수 있습니다.

template <typename T>
const dds::topic::PublicationBuiltinTopicData dds::sub::matched_publications_data(const dds::sub::DataReader<T><T>& dr, const dds::core::InstanceHandle& h)

DataReader와 연결된 publication의 discovery 데이터를 반환합니다. matched_publications()로 얻은 handle을 전달하세요. handle이 현재 연결된 publication을 식별하지 못하면 BadParameterError를 던집니다.

인프라가 subscription_data를 채우기 위하여 필요한 정보를 보유하지 않는 경우에도 작업은 실패할 수 있다. 이 경우에 작업은 UnsupportedError를 던질 것이다.
