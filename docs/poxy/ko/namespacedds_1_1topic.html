template <typename ANYTOPIC, typename FwdIterator>
int dds::topic::discover(FwdIterator begin, uint32_t max_size)

전진 반복자 Topic<T> 발견 입력 지점을 노출합니다.

매개변수
begin 출력 Topic<T> 발견을 위한 대상 반복자 예약
max_size 입력 요청한 결과의 최대 수
반환값
0 이 릴리스는 발견된 Topic을 반환하지 않습니다

void dds::topic::ignore(const dds::domain::DomainParticipant& dp, const dds::core::InstanceHandle& handle)

한 DomainParticipant에 대해 Topic을 무시하는 작업을 선언합니다

매개변수
dp 입력 Topic을 무시해야 하는 DomainParticipant
handle 입력 발견된 Topic<T> handle

이 선언은 네임스페이스에 정의되어 있습니다. 현재 구현 파일은 대신 전역 함수를 정의합니다.

template <typename FwdIterator>
void dds::topic::ignore(const dds::domain::DomainParticipant& dp, FwdIterator begin, FwdIterator end)

handle의 범위에 topic ignore를 적용합니다

매개변수
dp 입력 Topic을 무시해야 하는 DomainParticipant
begin 입력 범위의 첫번째 handle
end 입력 마지막 handle을 지나서 반복

단일 handle 네임스페이스 정규화 오버로드가 필요합니다.
