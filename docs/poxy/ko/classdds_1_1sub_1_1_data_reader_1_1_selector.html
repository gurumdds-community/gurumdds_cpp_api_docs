dds::sub::DataReader<T>::Selector 클래스

#include <gurumdds/cpp/sub/TDataReader.hpp>

상태, instance, 개수를 기준으로 sample을 선택합니다.

목차

  • Reference
    • 생성자, 소멸자, 변환 연산자
    • 공개 함수

새로운 선택자는 nil instance handle로 시작하고, 모든 상태 마스크가 사용되며, 명시적인 sample 제한이 없습니다. 해당 instance에만 레코드를 선택하도록 instance handle을 설정합니다. 선택자는 DataReader::default_filter_state()와 독립적으로 자체 상태 마스크를 저장합니다.

읽거나 가져오기 전에 이 선택자의 max_samples()로 sample 한도를 설정하세요. loaned collection을 반환하는 오버로드와 반복자를 받는 오버로드에 모두 적용합니다. 순방향 반복자를 받는 오버로드에서는 기본 구현 객체가 선택자의 한도를 사용하며, 대상에 반환하는 모든 레코드를 수용할 공간이 있어야 합니다.
