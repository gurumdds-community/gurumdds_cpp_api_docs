dds::core::cond::TWaitSet 클래스

첨부된 조건이 활성화될 때까지 기다림

애플리케이션이 다시 실행할 조건을 연결하세요. 가드 조건은 애플리케이션의 신호를, 상태 조건은 선택한 통신 상태의 변화를, 읽기 조건은 DataReader의 상태 마스크와 일치하는 sample의 존재를 나타냅니다.

wait(timeout)을 호출하고 반환된 조건 handle을 바탕으로 확인할 상태나 처리할 DataReader를 결정하세요. 반환값은 조건 handle 목록입니다. 실제 상태 또는 sample 데이터는 각각에 연결된 Entity에서 얻습니다. 애플리케이션 실행 중에 조건의 원본이 달라질 수 있으면 처리하기 전에 조건이나 Entity를 다시 확인하세요.

WaitSet마다 대기 스레드를 하나만 사용하세요. 대기 전에 condition 연결과 해제를 마치세요. C++ 래퍼는 동기화되지 않은 연결 목록으로 네이티브 대기 결과를 condition handle에 대응시킵니다.

시간 제한까지 활성 상태를 기다립니다

매개변수
timeout 입력 C 라이브러리에 전달된 최대 대기 시간
반환값 활성 조건, 또는 wait가 아무것도 보고하지 않으면 비어 있는 시퀀스

네이티브 대기는 차단하기 전에 연결된 조건을 확인하므로 이미 활성화된 조건은 바로 반환될 수 있습니다. dds::core::Duration::zero()를 폴링으로 전달하거나 유한 기간을 전달하여 대기를 제한합니다.

C++ 래퍼는 기본 조건 시퀀스를 읽고 기본 반환 코드를 무시한다. 비어 있는 결과는 시간이 지나거나 같은 WaitSet에 두 번째 웨이터가 있을 때와 같이 기본적으로 거부된 것을 의미할 수 있다.

WaitSet당 하나의 대기 스레드를 사용합니다. 대기를 시작하기 전에 첨부 파일을 변경하는 작업을 마칩니다.
