DomainParticipant는 DDS domain에 참여하며 Topic, Publisher, Subscriber의 생성에 필요합니다. 이 객체들보다 먼저 만드세요. 서로 발견해야 하는 애플리케이션에는 같은 domain ID를 사용하세요.

C++ API를 사용하려면 <gurumdds/dds.hpp>를 포함하세요. 예제의 첫 줄에서 domain ID를 정하고 다음 줄에서 participant라는 handle을 만듭니다. 완성 프로그램에서는 require()로 결과를 확인합니다.

domain에 DomainParticipant 생성

생성자에 domain ID를 전달하고 domain_id()로 확인합니다. 다른 domain에 속한 DomainParticipant는 같은 Topic 이름을 독립적으로 사용할 수 있습니다. 소속 Entity를 사용하는 동안 DomainParticipant의 수명을 유지하세요.

const dds::domain::DomainId domain = 92;

dds::domain::DomainParticipant participant(domain);

require(participant.domain_id() == domain, "Participant domain differs");

Domain ID는 discovery가 이루어지는 범위를 정합니다. Endpoint가 매칭되려면 Topic과 QoS도 호환되어야 합니다. DataWriter와 DataReader를 만든 후 확인할 사항은 Matching과 Discovery 에서 다룹니다.

QoS 설정 범위 선택

범위설정과 확인
이후 생성할 DomainParticipant생성 전에 DomainParticipant::default_participant_qos()로 설정합니다. 기본값과 새 DomainParticipant의 qos()를 읽어 확인합니다.
기존 DomainParticipant변경 가능한 정책을 participant.qos(value)로 설정하고 다시 읽습니다.
이후 생성할 Publisher와 SubscriberDomainParticipant의 자식 기본값을 설정하고 새 객체의 qos()를 읽습니다.

DomainParticipant의 UserData 설정

생성한 DomainParticipant의 QoS를 가져와 UserData를 바꾼 뒤 적용하세요. QoS를 다시 읽어 바이트 배열을 확인합니다.

using dds::core::policy::UserData;

const dds::core::ByteSeq data{1, 2, 3};

auto participant_qos = participant.qos();

participant_qos << UserData(data);

participant.qos(participant_qos);

require(participant.qos().policy<UserData>().value() == data, "Participant UserData differs");

다음 단계에서 설정하는 기본 QoS는 이후 생성할 Publisher와 Subscriber에 적용됩니다. 앞 단계의 UserData는 이미 만든 DomainParticipant 자체에 설정했습니다.

새 Publisher와 Subscriber의 기본 QoS 설정

Publisher와 Subscriber를 생성하기 전에 DomainParticipant의 기본 QoS를 설정하세요. QoS를 생략한 생성자는 이 기본값을 사용합니다. 이미 생성한 Entity는 자체 QoS를 변경하세요.

const dds::core::StringSeq partition_names{"defaults"};

auto default_publisher_qos = participant.default_publisher_qos();

default_publisher_qos << Partition(partition_names);

participant.default_publisher_qos(default_publisher_qos);



auto default_subscriber_qos = participant.default_subscriber_qos();

default_subscriber_qos << Partition(partition_names);

participant.default_subscriber_qos(default_subscriber_qos);



dds::pub::Publisher default_publisher(participant);

dds::sub::Subscriber default_subscriber(participant);

require(default_publisher.qos().policy<Partition>().name() == partition_names, "Publisher Partition differs");

require(default_subscriber.qos().policy<Partition>().name() == partition_names, "Subscriber Partition differs");

완성 프로그램에서는 participant로 publisher를 만들고, 그 Publisher와 Topic으로 writer를 만듭니다. 이렇게 해서 DomainParticipant의 직접 자식과 간접 자식을 각각 확인합니다.

Entity가 DomainParticipant에 속하는지 확인

Entity의 instance_handle()을 contains_entity()에 전달하세요. Publisher처럼 직접 생성한 Entity와 Publisher가 생성한 DataWriter를 모두 확인할 수 있습니다.

require(participant.contains_entity(publisher.instance_handle()), "Publisher is not contained");

require(participant.contains_entity(writer.instance_handle()), "Writer is not contained");

dds::domain::DomainParticipant other_participant(107);

require(not other_participant.contains_entity(writer.instance_handle()), "Another participant owns the writer");

같은 DomainParticipant에서 DDS timestamp를 얻습니다. DataWriter 튜토리얼에서는 이 timestamp를 sample에 넣어 보내는 방법을 설명합니다.

DomainParticipant에서 timestamp 가져오기

current_time()으로 얻은 타임스탬프를 쓰기 연산에 전달할 수 있습니다. 로컬 timeout은 단조 시계로 측정하세요.

const auto now = participant.current_time();

require(now.sec() >= 0, "Participant time is invalid");

Entity와 QoS

Entity를 생성하고 Partition과 endpoint 기본값을 설정한 뒤 DDS 예외를 처리합니다.

아래 명령으로 프로그램을 빌드하세요. 실행에 성공하면 Entity and QoS examples passed를 출력합니다.

cmake --build . --target example_cpp_howto_entities
완성 코드
#include "demo.hpp"



namespace

{

void use_entities()

{

    using howto::require;

    using dds::core::policy::History;

    using dds::core::policy::Partition;



    // [open_participant]

    const dds::domain::DomainId domain = 92;

    dds::domain::DomainParticipant participant(domain);

    require(participant.domain_id() == domain, "Participant domain differs");

    // [open_participant]



    // [participant_user_data]

    using dds::core::policy::UserData;

    const dds::core::ByteSeq data{1, 2, 3};

    auto participant_qos = participant.qos();

    participant_qos << UserData(data);

    participant.qos(participant_qos);

    require(participant.qos().policy<UserData>().value() == data, "Participant UserData differs");

    // [participant_user_data]



    // [participant_child_defaults]

    const dds::core::StringSeq partition_names{"defaults"};

    auto default_publisher_qos = participant.default_publisher_qos();

    default_publisher_qos << Partition(partition_names);

    participant.default_publisher_qos(default_publisher_qos);



    auto default_subscriber_qos = participant.default_subscriber_qos();

    default_subscriber_qos << Partition(partition_names);

    participant.default_subscriber_qos(default_subscriber_qos);



    dds::pub::Publisher default_publisher(participant);

    dds::sub::Subscriber default_subscriber(participant);

    require(default_publisher.qos().policy<Partition>().name() == partition_names, "Publisher Partition differs");

    require(default_subscriber.qos().policy<Partition>().name() == partition_names, "Subscriber Partition differs");

    // [participant_child_defaults]



    // [participant_time]

    const auto now = participant.current_time();

    require(now.sec() >= 0, "Participant time is invalid");

    // [participant_time]



    // [create_topic]

    dds::topic::Topic<Hello::Msg> topic(participant, "HowToEntities");

    const auto registered_type = dds::topic::topic_type_name<Hello::Msg>::value();

    require(topic.name() == "HowToEntities" and topic.type_name() == registered_type, "Topic description differs");

    // [create_topic]



    // [publisher_partition]

    auto publisher_qos = participant.default_publisher_qos();

    publisher_qos << Partition("howto");

    dds::pub::Publisher publisher(participant, publisher_qos);

    // [publisher_partition]



    // [publisher_participant]

    const auto owner = publisher.participant();

    require(owner == participant, "Publisher belongs to another participant");

    // [publisher_participant]



    // [subscriber_partition]

    auto subscriber_qos = participant.default_subscriber_qos();

    subscriber_qos << Partition("howto");

    dds::sub::Subscriber subscriber(participant, subscriber_qos);

    // [subscriber_partition]



    // [publisher_defaults]

    auto writer_defaults = publisher.default_writer_qos();

    writer_defaults << History::KeepLast(3);

    publisher.default_writer_qos(writer_defaults);

    dds::pub::DataWriter<Hello::Msg> writer(publisher, topic);

    require(writer.qos().policy<History>().depth() == 3, "Writer did not inherit history depth");

    // [publisher_defaults]



    // [participant_contains]

    require(participant.contains_entity(publisher.instance_handle()), "Publisher is not contained");

    require(participant.contains_entity(writer.instance_handle()), "Writer is not contained");

    dds::domain::DomainParticipant other_participant(107);

    require(not other_participant.contains_entity(writer.instance_handle()), "Another participant owns the writer");

    // [participant_contains]



    // [entity_nil]

    dds::pub::DataWriter<Hello::Msg> optional_writer(dds::core::null);

    require(optional_writer.is_nil(), "Empty writer handle is not nil");

    optional_writer = writer;

    require(not optional_writer.is_nil(), "Assigned writer handle is nil");

    // [entity_nil]



    // [subscriber_reader_qos]

    auto reader_qos = subscriber.default_datareader_qos();

    auto reader_history = reader_qos.policy<History>();

    reader_history.kind(dds::core::policy::HistoryKind::KEEP_LAST).depth(2);

    reader_qos.policy(reader_history);

    dds::sub::DataReader<Hello::Msg> reader(subscriber, topic, reader_qos);

    require(reader.qos().policy<History>().depth() == 2, "Reader did not use the requested history depth");

    // [subscriber_reader_qos]



    // [subscriber_check_settings]

    const auto subscriber_domain = subscriber.participant().domain_id();

    const auto subscriber_partitions = subscriber.qos().policy<Partition>().name();

    require(subscriber_domain == domain, "Subscriber domain differs");

    require(subscriber_partitions == dds::core::StringSeq{"howto"}, "Subscriber Partition differs");

    // [subscriber_check_settings]



    // [share_entity_handle]

    {

        const auto writer_alias = writer;

        require(writer_alias == writer, "Copied handle refers to a different writer");

    }

    require(not writer.is_nil(), "Releasing a copy affected the original");

    // [share_entity_handle]



    // [read_qos]

    History history;

    writer.qos() >> history;

    require(history.depth() == 3, "Could not extract writer history policy");

    // [read_qos]



    // [partition_delivery]

    auto other_qos = participant.default_subscriber_qos();

    other_qos << Partition("other");

    dds::sub::Subscriber other_subscriber(participant, other_qos);

    dds::sub::DataReader<Hello::Msg> other_reader(other_subscriber, topic, reader_qos);



    howto::wait_for_readers(writer, 1);

    char message[] = "partition example";

    Hello::Msg sample{};

    sample.userId = 7;

    sample.message = message;

    writer.write(sample);



    howto::wait_until([&reader, &sample]() -> bool {

        const auto batch = reader.take();

        for (const auto& received : batch)

            if (received.info().valid() and received.data().userId == sample.userId)

                return true;



        return false;

    }, "The reader in the matching partition did not receive the sample");



    require(writer.publication_matched_status().current_count() == 1, "Expected exactly one matched reader");

    require(other_reader.subscription_matched_status().current_count() == 0, "The reader in the other partition matched");

    require(other_reader.take().length() == 0, "The reader in the other partition received data");

    // [partition_delivery]

    std::cout << "Partition: one matched reader received the sample\n";

}



void catch_dds_exception()

{

    // [catch_dds_exception]

    try

    {

        const auto elapsed = dds::core::Duration::from_millisecs(20);

        const auto budget = dds::core::Duration::from_millisecs(10);

        const auto remaining = budget - elapsed;

        (void)remaining;

    }

    catch (const dds::core::InvalidDataError&)

    {

        std::cout << "Caught a negative duration\n";

        return;

    }

    // [catch_dds_exception]



    throw std::runtime_error("Expected InvalidDataError");

}

}



int main()

{

    return howto::run([]() -> void {

        use_entities();

        catch_dds_exception();

    }, "Entity and QoS examples passed");

}
