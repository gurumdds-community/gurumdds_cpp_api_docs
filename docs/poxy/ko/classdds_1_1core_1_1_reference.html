dds::core::Reference 클래스

#include <gurumdds/cpp/core/Reference.hpp>

DDS 참조 타입에 대한 공유-handle 연산을 정의합니다.

템플릿 매개변수
DELEGATE handle에 의해 공유되는 구현 개체의 타입

복사한 참조는 원본의 구현 객체를 공유합니다. dds::core::null을 대입하면 해당 참조를 비웁니다. 다른 소유자는 계속 사용할 수 있으며, 마지막 소유자가 참조를 놓으면 공유 포인터가 구현 객체를 소멸시킵니다. 네이티브 리소스 정리는 구체적인 구현 객체의 수명 규칙을 따릅니다.

handle 동등성은 저장된 구현 객체 포인터를 비교합니다. 구현 객체를 언급하지 않는 작업을 호출하기 전에, dds::core::null와 비어 있는 handle을 확인하십시오.

두 개체를 비교하고, 동일한 경우 true 를 반환합니다. 평등은 가리키는 개체의 참조적 평등에 기반을 두고 있습니다.

template <typename DELEGATE>
bool dds::core::Reference::operator==(const null_타입) const

반환값 이 참조가 null인 경우 true.

이 참조 객체가 null 참조와 같은지 검사하는 operator==입니다. bool is_null = (r == dds::null);와 같이 비교할 수 있습니다. r이 널 참조이면 is_null의 값은 true입니다.
