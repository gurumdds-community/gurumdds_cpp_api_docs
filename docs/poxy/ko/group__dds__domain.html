Reliable 송수신 튜토리얼 빌드 및 실행

Linux에서는 맞는 Conan profile로 저장소 루트에서 아래 명령을 실행하세요. 먼저 DDS 런타임을 설정하고 필요한 경우 SDK를 활성화하세요.

mkdir -p build/helloworld

cd build/helloworld

conan install --build missing ../..

cmake -DBUILD_EXAMPLE=ON ../..

cmake --build . --target example_cpp_programming_howto

./bin/example_cpp_programming_howto

Windows에서는 맞는 Conan profile을 준비하고 MSVC 2022는 ./build-msvc.ps1 -build_type Release, MinGW-w64는 ./build-mingw.ps1을 실행하세요. 빌드의 바이너리 디렉터리에서 선택한 구성으로 만들어진 example_cpp_programming_howto.exe를 실행합니다.

라이브러리를 찾지 못하면 Windows에서는 PATH, Linux에서는 LD_LIBRARY_PATH에 SDK와 바인딩의 런타임 디렉터리를 추가하세요. 실행에 성공하면 아래 줄이 출력됩니다. 코드는 reliable 전송과 수신 에 있습니다.

Received: Hello from the how-to

두 프로세스로 실행

sub_cpp와 pub_cpp target을 빌드하세요. Subscriber를 실행한 뒤 다른 터미널에서 Publisher를 실행합니다. 둘 다 domain 0과 HelloWorld Topic을 사용합니다. Subscriber는 sample을 받으면 Hello!를 출력합니다.

Legacy Publisher는 500 ms를 기다렸다가 한 번 발행합니다. Discovery가 더 오래 걸리면 DataWriter와 DataReader가 데이터를 교환하지 못할 때 진단하기 를 참조하세요. 전체 프로그램은 Hello World Publisher 와 Hello World Subscriber 에 있습니다.

설치된 SDK로 빌드

IDL에서 C++ 코드 생성 및 적용 의 독립 프로젝트를 사용하세요. CMake는 GURUMDDS_ROOT에서 C SDK 헤더와 라이브러리를, GURUMDDS_CXX_ROOT에서 C++ 바인딩 헤더와 라이브러리를 찾습니다. 바인딩과 gurumdds를 링크합니다.

생성된 타입 지원 파일이 이미 있다면 헤더와 링크 설정을 재사용하고 타입 지원 소스를 애플리케이션과 함께 컴파일하세요. 실행 전에 런타임 라이브러리 디렉터리를 추가합니다.
