status 사용 가능한 상태

StatusCondition을 활성화할 통신 상태를 지정합니다. 설정을 바꾸면 이 조건을 쓰는 WaitSet의 동작이 달라질 수 있습니다. 기본값은 모든 상태를 활성화합니다.

template <typename DELEGATE>
const ::dds::core::status::StatusMask dds::core::cond::TStatusCondition::enabled_statuses() const

StatusCondition의 trigger_value 계산에 사용하는 통신 상태 목록을 반환합니다. 이전에 enabled_statuses를 설정했다면 마지막에 명시한 목록을 반환합니다. 설정한 적이 없다면 기본 목록을 반환합니다(7.1.2.1.9.1절 참조).
