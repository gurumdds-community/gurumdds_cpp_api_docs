dds::core::Duration 클래스

#include <gurumdds/cpp/core/Duration.hpp>

초와 나노초로 간격을 나타냅니다.

목차

대기 시간, 임대 기간, 그 밖의 상대 시간 구간에는 초기화한 기간을 사용하세요. 변환 함수는 음이 아닌 기간을 초와 나머지 나노초로 나눕니다. 유한한 기간의 성분을 직접 제공할 때는 초를 0 이상으로 하고 나노초를 10억 미만으로 지정하세요.

infinite()는 무한대를 나타내는 특수 값입니다. 산술 연산에는 유한한 값을 사용하세요. 두 필드를 그대로 전달할 때는 값을 받는 C API의 무한대 표현을 확인하세요.

static const Duration dds::core::Duration::infinite()

C++ API에서 기본값으로 사용하는 무한 대기 시간을 반환합니다.

반환값 C++에서 무한 Duration을 나타내는 특수 값

C++의 특수 값은 두 필드에 모두 0x7fffffff를 사용합니다. 필드 값을 그대로 전달하기 전에 받는 C API에서 사용하는 무한대 표현을 확인하세요.

dds::core::Duration::Duration(int32_t sec, uint32_t nanosec = 0) explicit

초와 나노초로부터 지속시간을 구성합니다

매개변수
sec 입력 초
nanosec 입력 나노초 정수 초에 추가, 기본값은 0

두 인수를 그대로 저장합니다. 예를 들어 1.5초는 Duration(1, 500000000)으로 표현합니다. 유한한 간격에는 정규화된 값을 넘기거나 from_millisecs() 같은 변환 함수를 사용하세요.
