void dds::sub::SubscriberListener::on_data_on_readers(Subscriber& sub) pure virtual

Subscriber 아래의 하나 이상의 DataReader가 데이터를 사용할 수 있을 때 호출

매개변수
sub 입출력 이벤트를 보고하는 Subscriber

이 callback은 사용할 때 개별 DataReader<T> callback보다 우선합니다. 여기에서 sub.notify_datareaders() 를 호출하여 기록에 아직 sample이 있는 Subscriber의 DataReader에 대해 사용 가능한 on_data_available() callback을 예약합니다.
