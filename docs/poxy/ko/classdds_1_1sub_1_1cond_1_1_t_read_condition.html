#include <gurumdds/cpp/sub/cond/ReadCondition.hpp>

DataReader와 sample state 마스크와 관련된 조건을 설명합니다.

DataReader에 sample, 뷰, instance state 마스크와 일치하는 레코드가 있는지 감지하려면 이 조건을 WaitSet에 연결하세요. 한 DataReader에 서로 다른 마스크를 가진 읽기 조건을 여러 개 연결할 수 있습니다. WaitSet의 대기가 해제돼도 레코드를 소비하지 않습니다. 같은 마스크로 가져오거나 읽으려면 take() 또는 read()를 호출하기 전에 state_filter()의 반환값을 DataReader의 선택자에 지정하세요.
