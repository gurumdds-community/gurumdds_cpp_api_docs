dds::pub:: DataWriter<T> 클래스

#include <gurumdds/cpp/pub/DataWriter.hpp>

데이터 타입이 지정된 Topic에 sample을 쓰고 instance를 관리합니다.

DataWriter는 같은 domain의 Publisher를 통해 입력된 하나의 Topic에 대해 발행합니다. 기본 구현 객체는 Publisher 및 Topic handle의 사본을 유지합니다.

keyed Topic에서는, 각각의 다른 키가 instance를 식별합니다. 그 키로 sample을 작성하거나, 키를 등록하고 나중에 쓰기를 위해 반환된 instance handle을 다시 사용합니다.

void dds::pub::DataWriter::wait_for_acknowledgments(const dds::core::Duration& timeout)

뛰어난 신뢰할 수 있는 데이터를 인정하기 위해 기다립니다.

매개변수
timeout 입력 최대 대기 시간
예외
dds::core::TimeoutError 필요한 모든 확인이 도착하기 전에 대기 시간이 끝났습니다Name
dds::core::NotEnabledError DDS에서 이 DataWriter가 비활성 상태라고 보고했습니다.

reliable DataWriter에 양의 대기 시간을 지정하면 대기를 시작할 때 확인한 시퀀스 번호까지의 기록을 기다립니다. 연결된 reliable DataReader가 없어도 호출이 성공할 수 있습니다. DDS 수신 확인은 DataReader 측 수신을 확인합니다. 애플리케이션의 처리 여부는 별도로 확인해야 합니다.

활성화된 Best Effort DataWriter는 즉시 반환합니다. 대기 시간이 0이면 활성화된 DataWriter는 아직 도착하지 않은 확인 응답을 검사하지 않고 즉시 반환합니다.
