dds::sub::status::DataState 클래스

#include <gurumdds/cpp/sub/status/DataState.hpp>

sample, 뷰 및 instance state 마스크 결합

목차

  • Reference
    • 공개 정적 함수
    • 생성자, 소멸자, 변환 연산자
    • 공개 함수

레코드는 sample, 뷰, instance 세 마스크와 모두 일치해야 합니다. sample state는 읽은 레코드와 읽지 않은 레코드를 선택합니다. view state는 새 instance 세대와 이미 접근한 세대를 구분합니다. instance state는 활성 상태, 폐기 상태, DataWriter 없음 상태의 instance를 선택합니다. 기본 필터는 세 범주의 모든 값을 허용합니다.

모든 뷰와 instance state에서 읽지 않은 레코드에 대해 DataState(SampleState::not_read())를 사용합니다. 이러한 레코드를 라이브 instance로 제한하려면 세 마스크 생성자에서 InstanceState::alive()와 함께 ViewState::any()도 제공합니다.
