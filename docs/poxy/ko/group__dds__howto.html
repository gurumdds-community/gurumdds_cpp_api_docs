DomainParticipant 부터 시작하세요. Topic을 만든 뒤 송신 쪽에는 Publisher와 DataWriter를, 수신 쪽에는 Subscriber와 DataReader를 만듭니다. 직접 정의한 타입을 쓰려면 IDL에서 C++ 코드 생성 및 적용 를 이어서 확인하세요.

객체 튜토리얼에서는 같은 이름으로 handle을 부르며 생성 순서를 설명합니다. 각 완성 프로그램은 자체 domain ID와 Topic 이름을 사용합니다. 코드 조각을 한 프로그램에서 조합할 때는 송신과 수신 쪽의 domain과 Topic 이름을 맞추세요.

튜토리얼 프로그램 빌드 및 실행

첫 번째 sample 송수신 에 따라 SDK와 CMake로 저장소 빌드를 설정하세요. 빌드 디렉터리에서 각 튜토리얼의 빌드 명령을 실행하고 생성된 실행 파일을 실행하세요. 다중 구성 생성기에서는 --config Release처럼 구성을 지정하세요.

송수신 프로그램은 한 프로세스에서 두 endpoint를 만듭니다. 대부분 example/helloworld_keyed/HelloWorld.idl의 Hello::Msg를 사용합니다. 공통 검사와 대기 함수는 example/howto/demo.hpp에 있습니다.

처음 sample을 주고받을 때는 DataReader 튜토리얼의 reliable 전송과 수신 를 따라 하세요.
