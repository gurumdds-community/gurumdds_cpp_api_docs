template <typename D>
dds::topic::TSubscriptionBuiltinTopicData class

#include <gurumdds/cpp/topic/TBuiltinTopic.hpp>

Describes a discovered DataReader.

Contents

  • Reference
    • Base classes
    • Constructors, destructors, conversion operators
    • Public functions
    • Protected variables

Query a currently matched subscription through dds::pub::matched_subscription_data(). The value reports its topic, type, and advertised QoS. The built-in key identifies the subscription.
