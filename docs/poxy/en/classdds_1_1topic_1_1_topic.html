dds::topic:: Topic<T> class

#include <gurumdds/cpp/topic/Topic.hpp>

Associates a topic name with a DDS data type in a domain.

A topic name identifies a data channel within a DDS domain. Use the same topic name and compatible types for endpoints that should exchange samples. The type support supplies the data the participant needs to register T.

Use a topic to create typed readers and writers. For a reader that should receive a subset of samples, create a dds::topic::ContentFilteredTopic<T> based on the topic and attach the reader to that description.
