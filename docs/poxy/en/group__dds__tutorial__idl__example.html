The Topic tutorial used Hello::Msg generated by the repository build. Here you start from a new one-field Message type and generate both the C++ declaration and the type support needed to create a Topic.

Define a type in IDL

Create a project directory. In that directory, create Message.idl and enter the following type definition.

module IdlExample
{
    struct Message
    {
        long value;
    };
};

Generate the C++ type and type support

Open PowerShell in the project directory and set $sdk to the GurumDDS SDK path. Run GurumIDL with the cpp target, the IDL file, and an existing output directory.

$sdk = "C:/Program Files/Gurumnet/DDS"
cmake -E make_directory generated
& "$sdk/tool/gurumidl.exe" cpp Message.idl generated

GurumIDL generates the following files in generated.

  • Message.hpp defines the C++ type IdlExample::Message.
  • MessageTypeSupport.hpp declares the type support that Topic<IdlExample::Message> uses.
  • MessageTypeSupport.cpp implements the type support. Build it with the program.

Use the generated type in C++

Create main.cpp next to Message.idl. Include MessageTypeSupport.hpp and use IdlExample::Message as the template argument to Topic.

#include <exception>
#include <iostream>

#include "MessageTypeSupport.hpp"

int main()
try
{
    dds::domain::DomainParticipant participant(106);
    dds::topic::Topic<IdlExample::Message> topic(participant, "IdlExampleMessage");

    std::cout << "Topic: " << topic.name() << '\n';
    std::cout << "Type: " << topic.type_name() << '\n';
    return 0;
}
catch (const std::exception& error)
{
    std::cerr << error.what() << '\n';
    return 1;
}

Read the generated field types

IDL fieldGenerated C++ and data ownership
long valueA 32-bit integer field. Assign the value.
long bounds[2]An inline array. Copy its elements.
string labelA character pointer. Copy the text before returning the loan.
sequence<long> valuesA DDS long sequence pointer. Copy its elements while the loan is alive.

See Keep generated fields after returning a loan for the array, string, and sequence examples.

Add the CMake build

Create CMakeLists.txt in the project directory. It runs GurumIDL in the build directory, compiles MessageTypeSupport.cpp with main.cpp, and links the GurumDDS libraries.

cmake_minimum_required(VERSION 3.18)
project(IdlTutorial LANGUAGES CXX)

set(CMAKE_CXX_STANDARD 11)
set(CMAKE_CXX_STANDARD_REQUIRED ON)

set(GURUMDDS_ROOT "" CACHE PATH "GurumDDS SDK installation")
set(GURUMDDS_CXX_ROOT "${GURUMDDS_ROOT}" CACHE PATH "GurumDDS C++ binding installation")

find_program(GURUMIDL NAMES gurumidl HINTS "${GURUMDDS_ROOT}" PATH_SUFFIXES tool bin REQUIRED)
find_path(GURUMDDS_INCLUDE_DIR gurumdds/dds.h HINTS "${GURUMDDS_ROOT}" PATH_SUFFIXES include REQUIRED)
find_library(GURUMDDS_LIBRARY gurumdds HINTS "${GURUMDDS_ROOT}" PATH_SUFFIXES lib REQUIRED)
find_path(GURUMDDS_CXX_INCLUDE_DIR gurumdds/dds.hpp HINTS "${GURUMDDS_CXX_ROOT}" PATH_SUFFIXES include REQUIRED)
find_library(GURUMDDS_CXX_LIBRARY NAMES gurumdds_psm_cxx gurumdds_psm_cxxd
    HINTS "${GURUMDDS_CXX_ROOT}" PATH_SUFFIXES lib REQUIRED)

set(idl_file "${CMAKE_CURRENT_SOURCE_DIR}/Message.idl")
set(generated_dir "${CMAKE_CURRENT_BINARY_DIR}/generated")
set(type_source "${generated_dir}/MessageTypeSupport.cpp")
set(type_headers "${generated_dir}/Message.hpp" "${generated_dir}/MessageTypeSupport.hpp")

add_custom_command(
    OUTPUT "${type_source}" ${type_headers}
    COMMAND "${CMAKE_COMMAND}" -E make_directory "${generated_dir}"
    COMMAND "${CMAKE_COMMAND}" -E rm -f "${type_source}" ${type_headers}
    COMMAND "${GURUMIDL}" cpp "${idl_file}" "${generated_dir}"
    DEPENDS "${idl_file}" "${GURUMIDL}"
    VERBATIM
)

add_executable(idl_app main.cpp "${type_source}" ${type_headers})
target_include_directories(idl_app PRIVATE
    "${generated_dir}" "${GURUMDDS_CXX_INCLUDE_DIR}" "${GURUMDDS_INCLUDE_DIR}"
)
target_link_libraries(idl_app PRIVATE "${GURUMDDS_CXX_LIBRARY}" "${GURUMDDS_LIBRARY}")
target_compile_options(idl_app PRIVATE $<$<CXX_COMPILER_ID:MSVC>:/utf-8>)

Build and run

Use CMake 3.18 or later and a compiler with C++11 support. The commands below use PowerShell and a Visual Studio generator. Set GURUMDDS_ROOT to the SDK path and GURUMDDS_CXX_ROOT to the C++ binding path. Use the same path for both if they share an installation.

$sdk = "C:/Program Files/Gurumnet/DDS"
$cxx = "C:/path/to/gurumdds-cxx"
cmake -S . -B build "-DGURUMDDS_ROOT=$sdk" "-DGURUMDDS_CXX_ROOT=$cxx"
cmake --build build --config Debug

Add the directories containing the GurumDDS and C++ binding DLLs to PATH, then run the program. Successful output shows the Topic name and the registered type name.

$env:PATH = "$sdk/lib;$cxx/bin;$env:PATH"
./build/Debug/idl_app.exe
