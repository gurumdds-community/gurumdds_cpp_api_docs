dds::sub::DataReader<T>::Selector class

#include <gurumdds/cpp/sub/TDataReader.hpp>

Selects samples by state, instance, and count.

Contents

  • Reference
    • Constructors, destructors, conversion operators
    • Public functions

A new selector starts with a nil instance handle, all state masks enabled, and no explicit sample limit. Set an instance handle to select records for that instance only. The selector stores its own state masks independently of DataReader::default_filter_state().

Set the sample limit with max_samples() on this selector before reading or taking. This applies to both loan-returning and iterator overloads. For forward-iterator overloads, the default delegate uses the selector's limit, and the destination must have room for every returned record.
