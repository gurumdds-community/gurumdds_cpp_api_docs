dds::sub::LoanedSamples class

#include <gurumdds/cpp/sub/LoanedSamples.hpp>

Holds received samples and manages their middleware loan.

Template parameters
T Topic data type
TInfo Sample metadata type
DELEGATE Collection implementation template

Contents

  • Reference

The default delegate materializes C++ sample records in collection storage. It also holds the native sequences and reader delegate required to return the middleware loan. Copying a collection shares its records and loan. The last owner returns the loan and releases the native sequences.

Keep an owning collection alive while using iterators or references to its elements. Copy a sample by value when it must outlive the collection. Check sample.info().valid() before using sample.data(), since a record may contain metadata without an accessible payload.
