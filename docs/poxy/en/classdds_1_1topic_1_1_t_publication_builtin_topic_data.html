dds::topic::TPublicationBuiltinTopicData class

#include <gurumdds/cpp/topic/TBuiltinTopic.hpp>

Describes a discovered DataWriter.

Contents

  • Reference
    • Base classes
    • Constructors, destructors, conversion operators
    • Public functions
    • Protected variables

A publication discovery sample reports the DataWriter's topic, registered type, and advertised QoS. Its built-in key identifies the publication.
