dds::domain:: DomainParticipant class

#include <gurumdds/cpp/domain/DomainParticipant.hpp>

Joins a DDS domain and owns the entities created within it.

A domain ID identifies a DDS communication domain. Participants using the same domain ID can discover each other, subject to discovery configuration. Different domain IDs let independent DDS applications share the same physical network.

Create topics, publishers, and subscribers through a participant. Use different participants in one process to join different domains.

template <typename DELEGATE>
void dds::domain::TDomainParticipant::assert_liveliness()

Manually asserts liveliness through the participant.

For writers configured with MANUAL_BY_PARTICIPANT liveliness, service activity from the participant maintains their liveliness. Call this operation within the configured lease duration during periods when publication alone does not provide that activity. Use the writer's own assertion for MANUAL_BY_TOPIC.

template <typename DELEGATE>
bool dds::domain::TDomainParticipant::contains_entity(const ::dds::core::InstanceHandle& handle)

Parameters
handle the instance handle for which the containement relationship has to be checked.
Returns true if the handle belongs to an Entity belonging to this DomainParticipant

Checks whether or not the given a_handle represents an Entity that was created from the DomainParticipant. The containment applies recursively. That is, it applies both to entities (TopicDescription, Publisher, or Subscriber) created directly using the DomainParticipant as well as entities created using a contained Publisher, or Subscriber as the factory, and so forth.

template <typename DELEGATE>
int32_t dds::domain::TDomainParticipant::domain_id() const

Returns the domain id

Retrieves the domain_id used to create the DomainParticipant. The domain_id identifies the DDS domain to which the DomainParticipant belongs. As described in the introduction to Section 7.1.2.2.1, DomainParticipant Class, on page 22 each DDS domain represents a separate data communication plane isolated from other domains.
