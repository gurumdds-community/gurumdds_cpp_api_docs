template <typename T>
const dds::core::InstanceHandleSeq dds::sub::matched_publications(const dds::sub::DataReader<T><T>& dr)

Returns handles for writers on the same topic with compatible QoS that were not ignored through dds::domain::ignore. The handles are local and match SampleInfo::instance_handle in the DCPSPublications built-in topic. The operation can fail if the middleware does not keep connection information locally.

template <typename T>
const dds::topic::PublicationBuiltinTopicData dds::sub::matched_publications_data(const dds::sub::DataReader<T><T>& dr, const dds::core::InstanceHandle& h)

Returns discovery data for a publication that matches the reader. Pass a handle from matched_publications(). The operation throws BadParameterError if the handle does not identify a currently matched publication.

The operation may also fail if the infrastructure does not hold the information necessary to fill in the subscription_data. In this case the operation will throw UnsupportedError.
