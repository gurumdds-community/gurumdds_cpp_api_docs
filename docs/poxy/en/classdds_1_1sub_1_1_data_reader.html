dds::sub:: DataReader<T> class

#include <gurumdds/cpp/sub/DataReader.hpp>

Receives typed samples for a topic.

The reader selects samples from its local history using sample, view, and instance state masks. read() leaves the returned samples in the history and marks them as read. take() removes them from the history. Each result includes metadata, even when an instance-state notification carries no payload. Check sample.info().valid() before using sample.data(). Use the sample's metadata to inspect the instance state or obtain its handle when the payload is invalid.

Use the reader's default filter for routine access. Create a Selector with select() to set the instance, state masks, and record limit for a particular selection.

Reads samples that match the default state filter.

Returns Matching records, or an empty collection if no data matches, native sequence allocation fails, or the native operation returns an error

The reader retains the samples and marks them as read. A later operation that selects only unread samples will skip those records. Keep the collection alive while using its iterators or element references, and check SampleInfo::valid() before accessing a payload.

Reads matching samples into existing storage.

Parameters

max_samples in Maximum number of records, or zero for no explicit limit

Uses the reader's default state filter and copies each returned record and its metadata. The reader retains the returned records and marks them as read. For fixed-capacity storage, pass a positive limit representable by a signed 32-bit integer and provide at least that many writable positions. A zero limit passes the native unlimited value.

template <typename T, template<typename Q> class DELEGATE>
Selector dds::sub::DataReader::select()

Starts a new selection on this reader.

Returns Selector associated with this reader

Each call creates a selector with independent instance, state, and count filters. For example, given a reader dr and an instance handle obtained from that reader, take up to eight unread records for that instance. The sample-state filter leaves view and instance states unrestricted.

const dds::sub::status::DataState state(dds::sub::status::SampleState::not_read());
auto samples = dr.select().instance(handle).state(state).max_samples(8).take();

template <typename T, template<typename Q> class DELEGATE>
LoanedSamples<T> dds::sub::DataReader::take()

Takes samples that match the default state filter.

Returns Matching records, or an empty collection if no data matches, native sequence allocation fails, or the native operation returns an error

Taking removes the returned samples from the reader history, so a later read or take cannot retrieve those same records. Keep the collection alive while using its iterators or element references. Check SampleInfo::valid() to distinguish a data record from an instance-state notification.

template <typename SamplesFWIterator>
uint32_t dds::sub::DataReader::take(SamplesFWIterator sfit, uint32_t max_samples)

Takes matching samples into existing storage.

Parameters
sfit out First writable position for the returned records
max_samples in Maximum number of records, or zero for no explicit limit
Returns Number of records copied, or zero if the native operation produces no records

Uses the reader's default state filter and copies each returned record and its metadata. The reader removes the returned records from its history before copying begins. If writing to the destination throws, it may contain only some of the records. All removed records stay out of the reader history. For fixed-capacity storage, pass a positive limit representable by a signed 32-bit integer and provide at least that many writable positions. A zero limit passes the native unlimited value.
