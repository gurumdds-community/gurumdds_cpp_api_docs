dds::core::Duration class

#include <gurumdds/cpp/core/Duration.hpp>

Represents an interval in seconds and nanoseconds.

Contents

  • Reference
    • Public static functions
    • Constructors, destructors, conversion operators
    • Public functions

Use an initialized duration for a timeout, lease, or other relative interval. The conversion factories split a nonnegative interval into seconds and the remaining nanoseconds. When supplying the components directly for a finite interval, use nonnegative seconds and fewer than one billion nanoseconds.

Treat infinite() as a sentinel. Use finite values in arithmetic and verify the infinity representation of any native API that receives the two fields directly.
