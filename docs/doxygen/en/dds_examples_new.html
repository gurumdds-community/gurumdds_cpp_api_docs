New(C++17)

The examples below use revision b551d750d62f of GurumDDS C++ Examples.

Build with CMake 3.20 or later, a C++17 compiler, and the GurumDDS 3.2 SDK with its C and C++ libraries and GurumIDL.

Example Description
Hello World Send one typed sample. The Subscriber prints Received HelloWorld and the payload.
Keyed samples Register and look up instances by key. The Subscriber prints samples for the selected user_id.
DataReader listener Receive a sample through a callback. The Listener prints Received HelloWorld and the payload.
ContentFilteredTopic Filter by user_id. The Subscriber prints samples with the selected ID.
QoS profiles from XML Load an XML profile. The program prints default and profile QoS values for comparison.
Lifespan Compare a take before and after a sample expires. The expired sample no longer appears in the take result.
Deadline Pause writes past the deadline. The Listener reports a missed deadline.
TimeBasedFilter Send updates closer together than the configured minimum separation. The Subscriber receives only the samples admitted by the filter.
Liveliness Stop asserting manual liveliness and compare the reported live writer counts before and after lease expiry.

Build the New examples

On Linux, clone and check out the documented revision. Use the GurumDDS SDK and binding built for the same architecture and compiler ABI as the examples. Set up any required SDK license before running them.

git clone https://github.com/gurumdds-community/gurumdds_cpp_examples.git
cd gurumdds_cpp_examples
git checkout b551d750d62f70f76b39749a25747b9518f79055
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel
cd build/bin

CMake looks in /usr/share/gurumdds/cmake for a Linux package installation. For a custom SDK prefix, pass -DGurumDDS_DIR=/path/to/sdk/share/gurumdds/cmake when configuring. If the loader cannot find the SDK libraries, add their directory to LD_LIBRARY_PATH.

If the SDK config points to a missing tool/gurumidl but the package installs gurumidl on PATH, add this block after find_package(GurumDDS ...) in the community repository's top-level CMakeLists.txt. Then configure and build again.

if(NOT EXISTS "${GURUMIDL}")
unset(GURUMIDL)
find_program(GURUMIDL NAMES gurumidl REQUIRED)
endif()

Run each example's commands from build/bin. When there are two commands, start the Subscriber first and run the Publisher from the same directory in another terminal.
