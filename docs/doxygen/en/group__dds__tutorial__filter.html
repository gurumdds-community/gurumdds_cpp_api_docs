Content filters and receive callbacks
Programming Tutorials

Configure a ContentFilteredTopic before creating its DataReader to select samples by value. Use a Listener when the application needs notification that data is available. A notification can cover more than one sample, so read or take the available batch.

Start with the keyed Hello::Msg Topic from Topics and keyed types. The writer still publishes to that Topic. On the receiving side, create a filter that refers to its userId field and pass the filtered description to the reader.

Subscribe with a parameterized content filter

Apply a filter with ContentFilteredTopic. Bind the minimum key to %0 and the message text to %1. Pass the filtered topic to the reader constructor.

const dds::core::StringSeq parameters{ "5", "filter example" };
const dds::topic::Filter filter("userId > %0 AND message = %1", parameters);
dds::topic::ContentFilteredTopic<Hello::Msg> filtered(topic, "HowToFilterMinimum", filter);

Signal the application when data arrives

Start with an empty StatusMask and combine status bits with |=. The example enables data_available and sample_lost. The listener handles data availability and inherits the default no-op loss callback. Keep the listener alive while registered and until its callbacks finish.

class DataAvailable : public dds::sub::NoOpDataReaderListener<Hello::Msg>
{
public:
void on_data_available(dds::sub::DataReader<Hello::Msg>&) override
{
is_ready.store(true);
}
std::atomic<bool> is_ready{ false };
};
DataAvailable listener;
auto qos = subscriber.default_datareader_qos();
qos << dds::core::policy::History::KeepLast(4);
auto mask = dds::core::status::StatusMask::none();
mask |= dds::core::status::StatusMask::data_available();
mask |= dds::core::status::StatusMask::sample_lost();
dds::sub::DataReader<Hello::Msg> reader(subscriber, filtered, qos, &listener, mask);

The callback sets an atomic flag. The application clears it and takes samples in bounded batches until the reader returns an empty batch. One notification can cover several samples.

Change filter parameters for later samples

Check the parameter count in application code before calling filter_parameters(). The example catches a missing parameter, then verifies that a valid update changes which later samples pass the filter.

void set_filter_parameters(dds::topic::ContentFilteredTopic<Hello::Msg>& topic, const dds::core::StringSeq& parameters)
{
if (parameters.size() != 2)
throw std::invalid_argument("The filter requires a minimum key and a message");
topic.filter_parameters(parameters.begin(), parameters.end());
}
Filter parameter updates apply to later samples
set_filter_parameters(filtered, { "15", "filter example" });

Supply one string for each placeholder in order, starting at %0. After updating, write a fresh sample that passes and one that fails the filter. If the setter throws, the wrapper can report the requested values even though the native filter rejected them.

Content filter and listener

Receives samples through a parameterized content filter and a reader listener.

Build the program with the command below. A successful run prints Content filter and listener examples passed.

cmake --build . --target example_cpp_howto_filtering

#include <atomic>
#include "demo.hpp"
namespace
{
// [data_available_listener]
class DataAvailable : public dds::sub::NoOpDataReaderListener<Hello::Msg>
{
public:
void on_data_available(dds::sub::DataReader<Hello::Msg>&) override
{
is_ready.store(true);
}
std::atomic<bool> is_ready{ false };
};
// [data_available_listener]
void send_keys(dds::pub::DataWriter<Hello::Msg>& writer, int first, int second)
{
char text[] = "filter example";
Hello::Msg sample{};
sample.message = text;
sample.userId = first;
writer.write(sample);
sample.userId = second;
writer.write(sample);
}
// [checked_filter_parameters]
void set_filter_parameters(dds::topic::ContentFilteredTopic<Hello::Msg>& topic, const dds::core::StringSeq& parameters)
{
if (parameters.size() != 2)
throw std::invalid_argument("The filter requires a minimum key and a message");
topic.filter_parameters(parameters.begin(), parameters.end());
}
// [checked_filter_parameters]
void check_filtered_keys(dds::sub::DataReader<Hello::Msg>& reader, DataAvailable& listener, int expected_key,
unsigned int expected_count = 1)
{
// [take_after_callback]
unsigned int valid_count = 0;
howto::wait_until([&]() -> bool {
if (not listener.is_ready.exchange(false))
return false;
for (;;)
{
const auto samples = reader.select().max_samples(1).take();
if (samples.length() == 0)
break;
for (const auto& sample : samples)
{
if (not sample.info().valid())
continue;
howto::require(sample.data().userId == expected_key, "Filtered reader accepted an unexpected key");
++valid_count;
}
}
return valid_count == expected_count;
}, ("Unexpected payload count for key " + std::to_string(expected_key)).c_str());
// [take_after_callback]
}
void use_filter()
{
dds::domain::DomainParticipant participant(94);
dds::topic::Topic<Hello::Msg> topic(participant, "HowToFilter");
dds::pub::Publisher publisher(participant);
dds::sub::Subscriber subscriber(participant);
auto writer_qos = publisher.default_writer_qos();
writer_qos << dds::core::policy::History::KeepLast(4);
dds::pub::DataWriter<Hello::Msg> writer(publisher, topic, writer_qos);
// [configure_filter]
const dds::core::StringSeq parameters{ "5", "filter example" };
const dds::topic::Filter filter("userId > %0 AND message = %1", parameters);
dds::topic::ContentFilteredTopic<Hello::Msg> filtered(topic, "HowToFilterMinimum", filter);
// [configure_filter]
// [attach_listener]
DataAvailable listener;
auto qos = subscriber.default_datareader_qos();
qos << dds::core::policy::History::KeepLast(4);
auto mask = dds::core::status::StatusMask::none();
mask |= dds::core::status::StatusMask::data_available();
mask |= dds::core::status::StatusMask::sample_lost();
dds::sub::DataReader<Hello::Msg> reader(subscriber, filtered, qos, &listener, mask);
// [attach_listener]
dds::sub::DataReader<Hello::Msg> unfiltered_reader(subscriber, topic, qos);
howto::wait_for_readers(writer, 2);
send_keys(writer, 3, 7);
check_filtered_keys(reader, listener, 7);
// [update_filter]
set_filter_parameters(filtered, { "15", "filter example" });
// [update_filter]
bool rejected = false;
try
{
set_filter_parameters(filtered, { "15" });
}
catch (const std::invalid_argument&)
{
rejected = true;
}
howto::require(rejected, "Expected a missing filter argument to be rejected");
send_keys(writer, 8, 20);
check_filtered_keys(reader, listener, 20);
char other_message[] = "not a match";
Hello::Msg rejected_sample{};
rejected_sample.userId = 22;
rejected_sample.message = other_message;
writer.write(rejected_sample);
send_keys(writer, 21, 21);
check_filtered_keys(reader, listener, 21, 2);
unsigned int count = 0;
howto::wait_until([&unfiltered_reader, &count]() -> bool {
const auto samples = unfiltered_reader.take();
for (const auto& sample : samples)
if (sample.info().valid())
++count;
return count == 7;
}, "The unfiltered reader did not receive all samples");
}
}
int main()
{
return howto::run(use_filter, "Content filter and listener examples passed");
}
