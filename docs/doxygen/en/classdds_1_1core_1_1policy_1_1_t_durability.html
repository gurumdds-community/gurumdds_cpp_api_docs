Detailed Description

template<typename D>
class dds::core::policy::TDurability< D >

Controls whether samples written before a reader matches can reach that reader.

VOLATILE durability does not request historical samples. With TRANSIENT_LOCAL, the writer can supply retained samples to a compatible reader that matches later. History, resource limits, and sample lifespan govern which samples remain available.

The C++ binding stores VOLATILE and TRANSIENT_LOCAL. Both Transient() and Persistent() return TRANSIENT_LOCAL in this binding. These factories do not preserve samples after the writer is removed.
