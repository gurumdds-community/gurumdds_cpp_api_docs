Detailed Description

Owns writers and configures publication defaults.

Create one or more writers on a Publisher to send typed samples in the participant's domain. Publisher QoS applies to the group of writers. For example, the Partition policy affects which subscribers can match those writers. Configure writer policies separately when creating a DataWriter<T>.

Waits for reliable publications to be acknowledged.

This is a Publisher-wide wait. Use the DataWriter<T> operation to wait on a single writer. The duration applies to the whole Publisher wait. An acknowledgment confirms DDS receipt.
