Detailed Description

Publishes samples and manages instances for a typed topic.

A writer publishes on one typed topic through a Publisher in the same domain. The default delegate retains copies of the Publisher and Topic handles.

On a keyed topic, each distinct key identifies an instance. Write a sample with its key, or register the key and reuse the returned instance handle for subsequent writes. Set the keyed fields consistently when reusing a handle.

Choose a write operation
Goal Call When to use it
Write by key write(sample) Use the key in the sample to identify the instance.
Reuse a writer handle write(sample, handle) Keep the same key and use a handle from this writer.
Set source time write(sample, timestamp) Supply the time to put in the sample metadata.
Write a range write(begin, end) Write the records in the iterator range.

template<typename T, template< typename Q > class DELEGATE>
void dds::pub::DataWriter<T><T>< T, DELEGATE >::wait_for_acknowledgments ( const dds::core::Duration & timeout)
inline

Waits for outstanding reliable data to be acknowledged.

For a reliable writer and a positive timeout, the wait covers writes through the sequence number captured when the wait begins. The call can succeed with no matched reliable readers. DDS acknowledgments establish receipt. Application processing requires separate confirmation.

An enabled best-effort writer returns immediately. For an enabled writer, a zero timeout also returns immediately without checking outstanding acknowledgments.

Parameters
[in]timeoutMaximum wait duration
Exceptions
dds::core::TimeoutErrorThe wait expired before all required acknowledgments arrived
dds::core::NotEnabledErrorDDS reports that this writer is disabled

void dds::pub::DataWriter<T><T>< T, DELEGATE >::assert_liveliness ( )
inline

Manually asserts liveliness through this writer.

Use this call with MANUAL_BY_TOPIC liveliness to maintain this writer during periods without writes. Call it within the lease duration so matching readers can continue to consider the writer alive. For MANUAL_BY_PARTICIPANT liveliness, the participant can assert on behalf of its writers.

Exceptions
dds::core::NotEnabledErrorDDS reports that this writer is disabled
