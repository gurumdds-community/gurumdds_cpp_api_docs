Detailed Description

template<typename DELEGATE>
class dds::core::TEntityQos< DELEGATE >

Holds the policies for one category of DDS entity.

Each QoS type supports the policies available for that kind of entity. The default constructor loads the native defaults for the entity type. To start with a particular factory's defaults for new entities, retrieve them from that factory before changing individual policies.

Use policy(value) or the insertion operator to install a policy. The following example prepares a reader QoS with a keep-last depth of four. Pass the resulting QoS to the reader constructor or apply it with the reader's qos() setter, subject to the reader's policy mutability rules.

dds::sub::qos::DataReaderQos qos;
qos << dds::core::policy::History::KeepLast(4);
