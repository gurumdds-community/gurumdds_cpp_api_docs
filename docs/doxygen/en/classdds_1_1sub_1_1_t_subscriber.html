dds::sub::Subscriber

#include <gurumdds/cpp/sub/Subscriber.hpp>

Detailed Description

Owns readers and configures subscription defaults.

Create readers through this subscriber on topics in the associated participant's domain.

◆ notify_datareaders()

template<typename DELEGATE>
void dds::sub::Subscriber< DELEGATE >::notify_datareaders ( )

Requests data-available callbacks for this subscriber's readers.

The default delegate forwards the request to the native subscriber. The native subscriber schedules on_data_available() for each contained reader that has records in its history and a registered data-available callback. Use this operation in a subscriber-level on_data_on_readers() callback to hand processing to the individual reader callbacks.

Exceptions
dds::core::ExceptionThe C library returned an error
