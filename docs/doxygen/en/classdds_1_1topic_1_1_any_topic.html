dds::topic::AnyTopic Class
API modules » Topic

#include <gurumdds/cpp/topic/AnyTopic.hpp>

Detailed Description

Holds a topic without exposing its data type.

Use this handle to inspect topic QoS, the participant, or inconsistent-topic status. Recover a typed Topic<T><T> before creating a typed endpoint.
