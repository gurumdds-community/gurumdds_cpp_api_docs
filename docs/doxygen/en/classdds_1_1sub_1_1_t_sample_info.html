Detailed Description

template<typename DELEGATE>
class dds::sub::TSampleInfo< DELEGATE >

Describes a received sample and its instance state.

A record can report an instance state change such as disposal or loss of the last writer. In that case, use state().instance_state() and instance_handle() to identify the event and instance. Check valid() before accessing the accompanying payload. For a keyed topic, use the reader's key_value() with the instance handle to retrieve key fields for an instance still known to the reader.
