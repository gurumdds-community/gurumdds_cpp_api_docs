Retrieves a previously-created DataWriter<T> belonging to the Publisher that is attached to a Topic with a matching topic_name.

If no such DataWriter<T> exists, the operation will return an empty container. The use of this operation on the built-in Publisher allows access to the built-in DataWriter<T> entities for the built-in topics

◆ matched_subscription_data()

template<typename T>
const dds::topic::SubscriptionBuiltinTopicData dds::pub::matched_subscription_data ( const dds::pub::DataWriter<T>< T > & dw,
const ::dds::core::InstanceHandle & h )

Returns discovery data for a subscription that matches the writer.

Pass a handle from matched_subscriptions(). The operation throws BadParameterError if the handle does not identify a currently matched subscription.

The operation may also fail if the infrastructure does not hold the information necessary to fill in the subscription_data. In this case the operation will throw UnsupportedError.

◆ matched_subscriptions() [1/2]

template<typename T>
const ::dds::core::InstanceHandleSeq dds::pub::matched_subscriptions ( const dds::pub::DataWriter<T>< T > & dw)

Returns handles for readers on the same topic with compatible QoS that were not ignored through ignore_subscription.

The handles are local and match SampleInfo::instance_handle in the DCPSSubscriptions built-in topic. The operation can fail if the middleware does not keep connection information locally.
