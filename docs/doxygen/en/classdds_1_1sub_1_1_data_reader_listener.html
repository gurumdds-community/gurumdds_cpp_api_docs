Detailed Description

template<typename T>
class dds::sub::DataReaderListener< T >

Receives data availability and status notifications from a typed reader.

Callback summary
Callback When it runs Status argument
on_data_available() The reader has samples available. —
on_requested_deadline_missed() An instance misses its requested update interval. dds::core::status::RequestedDeadlineMissedStatus
on_requested_incompatible_qos() A discovered writer offers incompatible QoS. dds::core::status::RequestedIncompatibleQosStatus
on_sample_rejected() The reader rejects an incoming sample. dds::core::status::SampleRejectedStatus
on_liveliness_changed() A matched writer changes liveliness state. dds::core::status::LivelinessChangedStatus
on_subscription_matched() The set of matched publications changes. dds::core::status::SubscriptionMatchedStatus
on_sample_lost() The reader reports a sample loss. dds::core::status::SampleLostStatus

◆ on_data_available()

template<typename T>
virtual void dds::sub::DataReaderListener< T >::on_data_available ( DataReader<T>< T > & the_reader)
pure virtual

Called when the reader reports data available.

If the subscriber enables on_data_on_readers(), that callback receives the notification. It can call notify_datareaders() to schedule enabled data-available callbacks for readers with samples still in their history.
