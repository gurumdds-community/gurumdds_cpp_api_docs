dds::topic::ContentFilteredTopic<T>

#include <gurumdds/cpp/topic/ContentFilteredTopic.hpp>

Detailed Description

Selects samples from an existing topic by evaluating a filter expression.

Pass the filtered description to a reader. Writers continue to publish on the underlying topic with its original name and data type. For example, a filter expression userId > 5 selects samples whose userId field exceeds 5.

The filtered description keeps a reference to the exact Topic<T> object supplied at construction. Keep that object alive for the lifetime of the filtered topic.

Replaces the values bound to the expression placeholders.

Supply a value for each placeholder. The first string supplies %0, the second supplies %1, and so on. Existing readers on this description use the updated parameters after the C library accepts them. The expression itself stays the same. 

@param[in] parameters New expression parameters

@throw dds::core::Exception The C library returns an error the binding translates
