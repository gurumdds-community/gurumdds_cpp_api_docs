Detailed Description

template<typename D>
class dds::core::policy::THistory< D >

Controls retention of samples for each instance.

KEEP_LAST uses the configured depth for each instance. For example, KeepLast(4) configures retention of the last four samples for each key, subject to the entity's resource limits. Set a keep-last depth that fits within ResourceLimits::max_samples_per_instance().

KEEP_ALL selects retention subject to resource limits and does not use the history depth. This setting does not by itself enable late-joiner delivery. Set durability separately.
