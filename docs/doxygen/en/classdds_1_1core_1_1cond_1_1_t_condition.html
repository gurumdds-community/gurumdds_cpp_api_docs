Detailed Description

template<typename DELEGATE>
class dds::core::cond::TCondition< DELEGATE >

Supplies the common interface for WaitSet conditions.

A condition reports a Boolean trigger value. A guard condition exposes an application-controlled signal. A status condition monitors selected statuses on an entity. A read condition looks for samples that match sample, view, and instance state masks.

Use a WaitSet to retrieve triggered conditions, then consult the associated entity for the status or data. A trigger value can change after a wait returns, for example when another operation consumes matching samples.
