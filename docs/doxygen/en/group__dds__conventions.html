Conventions

Entity handles. Copying a handle shares the underlying entity. dds::core::null represents an empty handle. See dds::core::Reference for common operations.

Data and metadata. A read or take can report an instance state change without a payload. Check sample.info().valid() before accessing sample.data(). Keep dds::sub::LoanedSamples alive while using its iterators or element references.

QoS and errors. Check each QoS policy for its defaults and affected entities. Operations that translate native C errors can throw DDS exceptions. See each operation for its results and failure conditions.

What a copy shares

Copy Result
Duration or an individual QoS policy such as History A separate value. Editing the copy leaves the original value unchanged.
DataReader or DataWriter Another handle to the same entity. Changes to that entity are visible through both handles.
LoanedSamples Another owner of the same records and loan. The final owner returns the loan.
What survives after a copy is released

See Receive and select samples for ways to keep sample data beyond the lifetime of the loan.
