Publishers
Programming Tutorials

A Publisher owns the DataWriters created through it. Create a Publisher with your DomainParticipant, then use it with a typed Topic to create a DataWriter. Set the Publisher configuration before creating those writers.

Reuse participant from Domain participants. You will pass the Topic from Topics and keyed types to the DataWriter in the next chapter. Here you configure the common publication settings for writers created through this Publisher.

Create a Publisher

This constructor uses the participant's default Publisher QoS. It is enough for an application that uses the default partition on both sides.

dds::pub::Publisher publisher(participant);

With factory defaults, the Publisher uses the unnamed partition. The next example creates a Publisher with the named partition howto. Use that name in the corresponding Subscriber example.

Set the publishing partition

Set Partition before creating the writer. With a literal name such as howto, use the same partition name on the receiving subscriber.

auto publisher_qos = participant.default_publisher_qos();
publisher_qos << Partition("howto");
dds::pub::Publisher publisher(participant, publisher_qos);

Get the participant that owns a Publisher

Call publisher.participant() to get the participant used to create the Publisher. Copy the handle if you need to keep it separately.

const auto owner = publisher.participant();
require(owner == participant, "Publisher belongs to another participant");

A Publisher's Partition applies to its writers. DataWriter QoS controls the behavior of each writer. In the next snippet, set the default History depth and then create a writer that takes it from the Publisher.

Set defaults for new writers

Read the publisher defaults, adjust the desired policy, then call default_writer_qos(qos). A writer subsequently constructed without explicit QoS uses those defaults. The example checks its history depth.

auto writer_defaults = publisher.default_writer_qos();
writer_defaults << History::KeepLast(3);
publisher.default_writer_qos(writer_defaults);
dds::pub::DataWriter<Hello::Msg> writer(publisher, topic);
require(writer.qos().policy<History>().depth() == 3, "Writer did not inherit history depth");
