Detailed Description

template<typename DELEGATE>
class dds::sub::cond::TReadCondition< DELEGATE >

Describes a condition associated with a reader and sample-state masks.

Attach the condition to a WaitSet to detect whether its reader has a record matching the sample, view, and instance masks. A reader can have several read conditions with different masks. Waking the WaitSet does not consume any records. To take or read using the same masks, pass state_filter() to the reader's selector before calling take() or read().
