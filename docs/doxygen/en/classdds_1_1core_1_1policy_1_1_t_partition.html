Detailed Description

template<typename D>
class dds::core::policy::TPartition< D >

Controls logical publisher and subscriber matching within a domain.

Set partition names on the publisher and subscriber. DDS uses them when matching their writers and readers. A match requires at least one matching partition name in addition to topic and endpoint QoS compatibility. An empty partition list selects the default partition, whose name is the empty string.
