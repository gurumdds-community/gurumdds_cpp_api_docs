dds::sub::DataReader<T>

#include <gurumdds/cpp/sub/DataReader.hpp>

Detailed Description

Receives typed samples for a topic.

The reader selects samples from its local history using sample, view, and instance state masks. read() leaves the returned samples in the history and marks them as read. take() removes them from the history. Each result includes metadata, even when an instance-state notification carries no payload. Check sample.info().valid() before using sample.data(). Use the sample's metadata to inspect the instance state or obtain its handle when the payload is invalid.

Use the reader's default filter for routine access. Create a Selector with select() to set the instance, state masks, and record limit for a particular selection.

Choose a receive operation
Goal Call Filter or limit
Retain the records read() Uses the reader's default state.
Remove the records take() Uses the reader's default state.
Limit a single selection select().max_samples(n).take() Set state, instance, and count on the selector.
Copy into writable storage read(out, n) or take(out, n) Supply n writable positions and use a positive limit.

Gets the reader status for current and cumulative publication matches.

DDS captures a snapshot, then resets this status's change counters and clears its changed flag. Another observer may see zero changes, and an associated StatusCondition may stop triggering if no other enabled status is pending.
