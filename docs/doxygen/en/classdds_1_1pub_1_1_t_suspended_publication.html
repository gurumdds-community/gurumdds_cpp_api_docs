Detailed Description

template<typename DELEGATE>
class dds::pub::TSuspendedPublication< DELEGATE >

Manages a publisher scope for suspended publication.

Use this scope around a group of updates by writers on the same Publisher. Construction requests suspension from the C library. A successful call to resume() completes the request, and the scoped object also attempts to resume on destruction. Timing and buffering are determined by the native publisher.
