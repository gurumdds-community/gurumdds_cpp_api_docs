Detailed Description

Represents a timestamp as seconds and nanoseconds.

Set both components before reading a default-constructed timestamp. To retain fractions from an integer count, use from_microsecs() or from_millisecs(). The from_secs(double) overload currently drops the fractional part. Construct an explicit seconds and nanoseconds pair when finer precision is needed.

invalid() represents a marker rather than a timestamp for comparison or arithmetic. For comparisons, make sure the difference between whole-second fields fits an int, which is the type used by compare().
