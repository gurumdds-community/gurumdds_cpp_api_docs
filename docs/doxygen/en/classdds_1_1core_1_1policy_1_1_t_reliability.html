Detailed Description

template<typename D>
class dds::core::policy::TReliability< D >

Controls the delivery reliability a writer offers or a reader requests.

A reader requesting RELIABLE needs a writer offering RELIABLE. A reader requesting BEST_EFFORT can match either reliability kind if the other matching policies are compatible.

A reliable write may block when it needs space to keep data for delivery. Set max_blocking_time() to bound that wait. The endpoint's history and resource limits still govern sample retention. The DataWriter factory default is 100 ms. The Reliable() factory uses Duration::infinite() when no argument is supplied. Pass a finite duration to Reliable(duration) to set a known limit.
