This reference describes C++ binding 1.3.2. Match the architecture and compiler ABI of the SDK, binding, and application. Set up any license required by your SDK before running the programs.

Build the C++ binding and run a reliable round trip on Linux

Use a Conan 1 profile that matches your GCC version, architecture, and C++ standard library ABI. Run these commands from the C++ binding repository root. Replace gcc-release with your profile name.

conan install . -if build/tutorials --build=missing -pr gcc-release -s build_type=Release
cmake -S . -B build/tutorials -DCMAKE_BUILD_TYPE=Release -DBUILD_EXAMPLE=ON
cmake --build build/tutorials --target example_cpp_programming_howto
./build/tutorials/bin/example_cpp_programming_howto

With CMake 4, add -DCMAKE_POLICY_VERSION_MINIMUM=3.5 to the configure command for the repository's older CMake files.

If the loader cannot find a shared library, add the directories containing libgurumdds.so and libgurumdds_psm_cxx.so to LD_LIBRARY_PATH. The Release build also copies the binding and headers into output/lib and output/include for use by a separate project.

The program creates both endpoints in one process, waits for a match, and verifies one read and one take. It prints the following line. See Reliable send and receive for the code.

Received: Hello from the how-to

Run the two-process example on Linux

Build the legacy Publisher and Subscriber in the same build directory.

cmake --build build/tutorials --target sub_cpp pub_cpp

Run the Subscriber in one terminal.

./build/tutorials/bin/sub_cpp

Run the Publisher from the repository root in a second terminal with the same SDK runtime setup.

./build/tutorials/bin/pub_cpp

Both processes join domain 0 and use the HelloWorld Topic. The Subscriber prints Hello! when it receives the sample. The legacy Publisher waits 500 ms and writes once. See Diagnose a writer and reader that do not exchange data if discovery takes longer. See Hello World Publisher and Hello World Subscriber for the source.

Build against an installed SDK

Start with Generate and use C++ code from IDL to generate a C++ type and register a Topic. Its CMake project uses GURUMDDS_ROOT for the native SDK and GURUMDDS_CXX_ROOT for the C++ binding. It compiles the generated type-support source and links the two libraries. If your application already has generated type support, use the same include and link settings.

To verify communication with an installed SDK, build Hello World with a C++17 compiler and run its Subscriber and Publisher. The Subscriber prints Received HelloWorld and the payload.
