Detailed Description

Domain participants and remote participant discovery.

A participant owns the topics, publishers, and subscribers it creates in its DDS domain.

This reference describes C++ binding 1.3.2. Match the SDK and binding architecture and compiler ABI. For MSVC, use the runtime for the selected configuration.

Build and run the reliable tutorial

On Linux, run the following commands from the repository root with a matching Conan profile. Set up the DDS runtime and any required SDK activation first.

mkdir -p build/helloworld
cd build/helloworld
conan install --build missing ../..
cmake -DBUILD_EXAMPLE=ON ../..
cmake --build . --target example_cpp_programming_howto
./bin/example_cpp_programming_howto

On Windows, run ./build-msvc.ps1 -build_type Release for MSVC 2022 or ./build-mingw.ps1 for MinGW-w64 with a matching Conan profile. Run example_cpp_programming_howto.exe from the build's binary directory using the selected configuration.

If the loader cannot find the libraries, add the SDK and binding runtime directories to PATH on Windows or LD_LIBRARY_PATH on Linux. A successful run prints the line below. See Reliable send and receive for the code.

Received: Hello from the how-to

Run the two-process example

Build the sub_cpp and pub_cpp targets. Start the subscriber, then run the publisher in a second terminal. Both join domain 0 and use the HelloWorld topic. The subscriber prints Hello! when it receives the sample.

The legacy publisher waits 500 ms and writes once. See Diagnose a writer and reader that do not exchange data if discovery takes longer. The programs are in Hello World Publisher and Hello World Subscriber.

Build against the installed SDK

Use the standalone project in Generate and use C++ code from IDL. Its CMake file locates the SDK headers and library with GURUMDDS_ROOT and the C++ binding headers and library with GURUMDDS_CXX_ROOT. It links the binding and gurumdds.

For an application with generated type support already available, reuse the include and link settings and compile the generated type-support source with your application. Add the runtime library directories before running it.
