Detailed Description

template<typename D>
class dds::core::policy::TTopicData< D >

This QoS lets the application attach additional information to the created Topic such that when a remote application discovers their existence it can examine the information and use it in an application-defined way.

In combination with the listeners on the DataReader and DataWriter as well as by means of operations such as ignore_topic, these QoS can assist an application to extend the provided QoS.
