Detailed Description

template<typename D>
class dds::core::policy::TPresentation< D >

Configures presentation scope and requests coherent or ordered access.

Set this policy on a publisher or subscriber. The scope identifies whether the presentation rules apply within a single instance or across instances of a topic. Coherent access requests that related updates be made available as a set. Ordered access requests that the middleware preserve their order within the scope.

The standalone policy defaults to INSTANCE with both flags disabled. The full DDS object model profile is disabled in this binding. In particular, GroupAccessScope() creates an INSTANCE policy.
