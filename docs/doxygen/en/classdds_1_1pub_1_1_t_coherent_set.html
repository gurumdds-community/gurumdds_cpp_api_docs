Detailed Description

template<typename DELEGATE>
class dds::pub::TCoherentSet< DELEGATE >

Manages a publisher scope for a set of coherent changes.

When the native library supports coherent presentation, a set groups related changes from writers owned by the same Publisher. For example, a reader can observe updates to two related instances as a unit. The constructor and end() forward to the native coherent-change operations. The default DDS object model profile is disabled, so applications should check native support before using this scope.
