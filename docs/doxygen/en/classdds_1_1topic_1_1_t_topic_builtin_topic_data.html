Detailed Description

template<typename D>
class dds::topic::TTopicBuiltinTopicData< D >

Describes a topic reported by DDS discovery.

A topic discovery sample carries the topic name, registered type name, and advertised QoS. Its built-in key identifies the discovered topic.
