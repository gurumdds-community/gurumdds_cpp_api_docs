Detailed Description

Publishers, writers, and publication status Create a writer for a topic and use the writer to publish data or update an instance's lifecycle.

Type Use
Publisher Creates writers and supplies their default QoS.
DataWriter<T> Writes samples and manages keyed instances.

Handle publication events

Type Use
DataWriterListener<T> Receives status callbacks from a typed writer.

Work with keyed samples

Type Use
