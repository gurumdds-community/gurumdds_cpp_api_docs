GurumDDS C++ API Reference

GurumDDS implements the DDS C++ Platform-Specific Model on the GurumDDS C library. Applications exchange samples through typed topics, writers, and readers. Include <gurumdds/dds.hpp> for the full API or use the installed headers listed on each reference page.

This API requires C++11. The New examples require C++17.

API modules

  • Domain. Join a domain and look up participants and discovered endpoints.
  • Topic. Associate topic names with data types and set up content filters.
  • Publication. Create publishers and writers, publish samples, and manage instances.
  • Subscription. Create subscribers and readers, select samples, and access sample data and metadata.
  • Core. Work with entity handles, time, conditions, QoS, and exceptions.
