Detailed Description

Start with Domain participants. Create a Topic, then create a Publisher and DataWriter on the sending side and a Subscriber and DataReader on the receiving side. Follow Generate and use C++ code from IDL when you are ready to define your own type.

The object tutorials explain this sequence using the same names for handles. Each complete program sets its own domain ID and topic name. When combining snippets in your program, use the same domain and topic name on both sides.

Build and run the tutorial programs

Configure the repository build with the SDK and CMake as described in Send and receive your first sample. Run each tutorial's build command from that build directory and run the resulting executable. With a multi-configuration generator, add a configuration such as --config Release.

The send-and-receive programs create both endpoints in one process. Most use Hello::Msg from example/helloworld_keyed/HelloWorld.idl. Shared checks and waits are defined in example/howto/demo.hpp.

For a first send-and-receive run, follow Reliable send and receive in the DataReader tutorial.
