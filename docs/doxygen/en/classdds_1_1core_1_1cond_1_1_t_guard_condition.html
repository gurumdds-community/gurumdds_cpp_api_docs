Detailed Description

template<typename DELEGATE>
class dds::core::cond::TGuardCondition< DELEGATE >

Signals a WaitSet from application code.

Attach the condition to a WaitSet before using it to signal a waiting thread. Setting the trigger to true requests a wake-up. Waiting does not clear the trigger. Reset it explicitly after handling the signal if the WaitSet should block again.

Keep the guard condition alive while the WaitSet uses it. Its destructor deletes the native condition.
