Detailed Description

Combines sample, view, and instance state masks.

A record must match the sample, view, and instance masks. Sample state selects read or unread records. View state distinguishes a new instance generation from one already accessed. Instance state selects alive, disposed, or no-writers instances. The default filter accepts all values in all three categories.

Use DataState(SampleState::not_read()) for unread records across all views and instance states. To restrict those records to live instances, also supply InstanceState::alive() together with ViewState::any() in the three-mask constructor.
