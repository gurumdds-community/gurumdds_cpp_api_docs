Matching and discovery
Programming Tutorials

Detailed Description

Create both endpoints before checking discovery. Use the current match count to see whether an endpoint has a compatible peer. If you need to know which peer matched, list the handles and inspect their discovery data.

Use the writer and reader from the preceding entity tutorials. A match means these endpoints can exchange samples. To confirm a specific sample was received, check the receiving application's output or payload.

List matched readers and inspect subscription data

Use matched_subscriptions() on the writer to get reader handles. Pass one to matched_subscription_data() to inspect the reader's topic name, type name, and Reliability setting.

const auto subscriptions = dds::pub::matched_subscriptions(writer);
howto::require(subscriptions.size() == 1, "Expected one matched subscription");
const auto subscription = dds::pub::matched_subscription_data(writer, subscriptions.front());
howto::require(subscription.topic_name() == topic.name(), "Matched subscription has a different topic");
howto::require(subscription.type_name() == topic.type_name(), "Matched subscription has a different type");
howto::require(subscription.reliability().kind() == reader.qos().policy<dds::core::policy::Reliability>().kind(),
"Matched subscription reported a different reliability kind");

List matched writers

matched_publications() returns a snapshot of writer handles. This example creates one writer and expects one handle.

const auto publications = dds::sub::matched_publications(reader);
howto::require(publications.size() == 1, "Expected one matched publication");

Read match counts and changes together

Use one publication_matched_status() snapshot when you need both the current count and its change. Reading the status clears its change counts on the writer. The snapshot retains the values from that call.

When the only reader matches, both counts and both change counts are one. The example reads again before another event and verifies that both change counts are zero. When the reader later leaves, the current count returns to zero and the cumulative count stays at one.

Current matches, cumulative matches and changes
howto::wait_until([&writer]() -> bool {
const auto matched = writer.publication_matched_status();
if (matched.current_count() != 1)
return false;
howto::require(matched.total_count() == 1 and matched.current_count_change() == 1
and matched.total_count_change() == 1, "Expected one new match in the snapshot");
const auto unchanged = writer.publication_matched_status();
howto::require(unchanged.current_count() == 1 and unchanged.total_count() == 1
and unchanged.current_count_change() == 0 and unchanged.total_count_change() == 0,
"Reading the status did not clear the change counts");
return true;
}, "The reader did not match");

Refresh the match list after a reader exits

A handle can become stale between listing the matches and looking up metadata. If the peer is gone, refresh the list. The example closes its only reader and waits for the writer to report zero matches and an empty list.

Refresh the matched Reader snapshot after an exit
howto::wait_until([&writer]() -> bool {
if (not dds::pub::matched_subscriptions(writer).empty())
return false;
const auto unmatched = writer.publication_matched_status();
if (unmatched.current_count() != 0)
return false;
howto::require(unmatched.total_count() == 1, "Losing the match changed the cumulative count");
return true;
}, "The reader did not disappear from the writer's matches");

Endpoint discovery

Lists matched reader and writer handles and inspects discovered subscription metadata.

Build the program with the command below. A successful run prints Endpoint discovery examples passed.

cmake --build . --target example_cpp_howto_discovery
Complete source
#include "demo.hpp"
#include <gurumdds/cpp/pub/discovery.hpp>
#include <gurumdds/cpp/sub/discovery.hpp>
namespace
{
void use_discovery()
{
dds::domain::DomainParticipant participant(95);
dds::topic::Topic<Hello::Msg> topic(participant, "HowToDiscovery");
dds::pub::Publisher publisher(participant);
dds::sub::Subscriber subscriber(participant);
dds::pub::DataWriter<Hello::Msg> writer(publisher, topic);
{
dds::sub::DataReader<Hello::Msg> reader(subscriber, topic);
// [match_status_snapshot]
howto::wait_until([&writer]() -> bool {
const auto matched = writer.publication_matched_status();
if (matched.current_count() != 1)
return false;
howto::require(matched.total_count() == 1 and matched.current_count_change() == 1
and matched.total_count_change() == 1, "Expected one new match in the snapshot");
const auto unchanged = writer.publication_matched_status();
howto::require(unchanged.current_count() == 1 and unchanged.total_count() == 1
and unchanged.current_count_change() == 0 and unchanged.total_count_change() == 0,
"Reading the status did not clear the change counts");
return true;
}, "The reader did not match");
// [match_status_snapshot]
std::cout << "Match status: reading it cleared the change counts\n";
// [matched_readers]
const auto subscriptions = dds::pub::matched_subscriptions(writer);
howto::require(subscriptions.size() == 1, "Expected one matched subscription");
const auto subscription = dds::pub::matched_subscription_data(writer, subscriptions.front());
howto::require(subscription.topic_name() == topic.name(), "Matched subscription has a different topic");
howto::require(subscription.type_name() == topic.type_name(), "Matched subscription has a different type");
howto::require(subscription.reliability().kind() == reader.qos().policy<dds::core::policy::Reliability>().kind(),
"Matched subscription reported a different reliability kind");
// [matched_readers]
// [matched_writers]
const auto publications = dds::sub::matched_publications(reader);
howto::require(publications.size() == 1, "Expected one matched publication");
// [matched_writers]
}
// [match_after_reader_exit]
howto::wait_until([&writer]() -> bool {
if (not dds::pub::matched_subscriptions(writer).empty())
return false;
const auto unmatched = writer.publication_matched_status();
if (unmatched.current_count() != 0)
return false;
howto::require(unmatched.total_count() == 1, "Losing the match changed the cumulative count");
return true;
}, "The reader did not disappear from the writer's matches");
// [match_after_reader_exit]
}
}
int main()
{
return howto::run(use_discovery, "Endpoint discovery examples passed");
}
