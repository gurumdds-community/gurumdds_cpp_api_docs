Detailed Description

template<typename DELEGATE>
class dds::core::TEntity< DELEGATE >

Provides common operations on a DDS entity handle.

Participants, topics, publishers, subscribers, writers, and readers share these operations. A copy of an entity handle shares the same delegate. Entity-specific QoS accessors, listener operations, and status getters belong to the corresponding derived type.

A handle may be empty. Check it against dds::core::null before calling members that forward to the delegate.

void dds::core::TEntity< DELEGATE >::enable ( )

Requests that the C layer enable this entity.

Child creation uses the factory's EntityFactory QoS policy to control automatic enabling. When enabling manually, enable the creating entity before enabling its children.

The wrapper forwards the request to the C API and discards the status code. Normal return therefore does not confirm that the entity accepted the request.

◆ retain()

template<typename DELEGATE>
void dds::core::TEntity< DELEGATE >::retain ( )
inline

Marks the native entity as retained by the delegate.

Sets the shared delegate's native ownership marker, which is visible through other handles that share that delegate. Destructors that check the marker, such as the participant's, skip native deletion when it is set. This call does not keep the C++ delegate alive after its owning handles have been released.

Exposes the entity's status-change query.

The default delegate returns an empty status mask regardless of pending communication events. To react to changes, select statuses on a StatusCondition or register a listener. Read the corresponding entity-specific status to obtain its counters and any associated handles.
