Topic
API modules

Detailed Description

Typed topics, topic descriptions, and content filters Use the same topic name and compatible type on the writer and reader sides.

Topic inheritance

Topic and ContentFilteredTopic inherit from TopicDescription. When creating a ContentFilteredTopic, pass the underlying Topic and a Filter. Keep that Topic object alive for the lifetime of the filtered topic.
