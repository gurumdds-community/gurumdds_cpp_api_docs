class dds::pub::TCoherentSet< DELEGATE >

일관된 변경 사항의 세트에 대한 Publisher 범위를 관리합니다.

네이티브 라이브러리가 일관된 표시를 지원하면 같은 Publisher가 소유한 DataWriter에서 발생한 관련 변경을 하나의 집합으로 묶습니다. 예를 들어 DataReader가 서로 관련된 두 instance의 갱신을 한 단위로 볼 수 있습니다. 생성자와 end()는 네이티브의 일관된 변경 연산을 호출합니다. 기본 DDS 객체 모델 프로파일은 비활성화돼 있으므로 이 범위를 사용하기 전에 네이티브 라이브러리의 지원 여부를 확인하세요.

Publisher에 대한 coherent-change 범위를 시작합니다.

관련 변경사항을 게시하는 동안 이 개체를 살아있게 유지한다. end() 를 호출하여 명시적으로 완료 요청한다. 저장된 구현 객체는 또한 범위가 활성 상태로 남아 있으면 파괴 시에도 완료를 요청한다.

매개변수
[입력]pubDataWriter가 업데이트한 Publisher가 세트를 구성합니다.
예외
dds::core::ExceptionC 라이브러리는 시작 요청을 거부하고 바인딩은 반환 코드를 번역합니다.

coherent- change 범위를 끝냅니다

기본 델리게이트는 하나의 호출이 성공할 때까지 네이티브 end 연산을 호출한다. 나중에 같은 개체를 호출하면 C 라이브러리를 호출하지 않고 반환한다.
