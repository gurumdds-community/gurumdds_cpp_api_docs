dds::pub::Publisher

#include <gurumdds/cpp/pub/Publisher.hpp>

상세한 설명

DataWriter를 소유하고 게시 기본값을 구성합니다.

DomainParticipant의 domain에서 데이터 타입을 지정한 sample을 보내려면 하나의 Publisher에 DataWriter를 하나 이상 생성하세요. Publisher QoS는 DataWriter<T> 그룹에 적용합니다. 예를 들어 Partition 정책은 그 DataWriter들과 연결할 수 있는 Subscriber에 영향을 줍니다. DataWriter별 정책은 DataWriter를 만들 때 따로 설정하세요.

기본 DataWriter<T> QoS를 업데이트합니다.

QoS를 지정하지 않은 DataWriter는 생성 시 DDS 기본값을 사용합니다. 이미 생성된 DataWriter는 기존 정책을 유지합니다. C API는 새 정책이 서로 호환되는지 확인한 뒤 적용합니다.
