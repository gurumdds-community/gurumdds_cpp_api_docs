IDL 타입에서 애플리케이션까지 빌드

Topic 튜토리얼에서는 저장소 빌드가 생성한 Hello::Msg를 사용했습니다. 여기서는 필드가 하나인 Message부터 정의하고, Topic 생성에 필요한 C++ 선언과 타입 지원 코드를 직접 만듭니다.

IDL 타입 정의

프로젝트 디렉터리를 만듭니다. 그 안에 Message.idl을 만들고 다음 타입을 정의하세요.

module IdlExample
{
struct Message
{
long value;
};
};

C++ 타입과 타입 지원 코드 생성

빌드할 때 CMake가 GurumIDL을 실행합니다. 생성 파일을 먼저 확인하려면 GurumIDL에 cpp, IDL 파일, 미리 만든 출력 디렉터리를 전달합니다. Linux SDK 패키지가 /usr에 설치되어 있다면 프로젝트 디렉터리에서 아래 명령을 실행합니다. 설치 위치가 다르면 SDK와 실행 파일 경로를 바꿉니다.

sdk=/usr
mkdir -p generated
"$sdk/bin/gurumidl" cpp Message.idl generated

GurumIDL은 generated에 다음 파일을 생성합니다.

  • Message.hpp는 C++ 타입 IdlExample::Message를 정의합니다.
  • MessageTypeSupport.hpp는 Topic<IdlExample::Message>에 필요한 타입 지원을 선언합니다.
  • MessageTypeSupport.cpp는 타입 지원을 구현합니다. 프로그램을 빌드할 때 이 파일도 컴파일하세요.

생성된 타입을 C++에 적용

Message.idl과 같은 디렉터리에 main.cpp를 만드세요. MessageTypeSupport.hpp를 포함하고 Topic의 템플릿 인수로 IdlExample::Message를 지정합니다.

#include <exception>
#include <iostream>
#include "MessageTypeSupport.hpp"
int main()
try
{
dds::domain::DomainParticipant participant(106);
dds::topic::Topic<IdlExample::Message> topic(participant, "IdlExampleMessage");
std::cout << "Topic: " << topic.name() << '\n';
std::cout << "Type: " << topic.type_name() << '\n';
return 0;
}
catch (const std::exception& error)
{
std::cerr << error.what() << '\n';
return 1;
}

생성된 필드 타입 확인

IDL 필드 생성된 C++와 데이터 소유권
long value 32비트 정수 필드이며 값을 대입합니다.
long bounds[2] 구조체에 포함된 배열이며 원소를 복사합니다.
string label 문자 포인터입니다. Loan 반환 전에 문자열을 복사합니다.
sequence<long> values DDS long 시퀀스 포인터입니다. Loan이 유효한 동안 원소를 복사합니다.

배열, 문자열, 시퀀스 예제는 loan 반환 후에도 생성 타입의 필드 사용 에 있습니다.

CMake 빌드 설정

프로젝트 디렉터리에 CMakeLists.txt를 만드세요. CMake는 빌드 디렉터리에서 GurumIDL을 실행하고 MessageTypeSupport.cpp와 main.cpp를 컴파일한 뒤 GurumDDS 라이브러리를 링크합니다.

cmake_minimum_required(VERSION 3.18)
project(IdlTutorial LANGUAGES CXX)
set(CMAKE_CXX_STANDARD 11)
set(CMAKE_CXX_STANDARD_REQUIRED ON)
set(GURUMDDS_ROOT "" CACHE PATH "GurumDDS SDK installation")
set(GURUMDDS_CXX_ROOT "${GURUMDDS_ROOT}" CACHE PATH "GurumDDS C++ binding installation")
find_program(GURUMIDL NAMES gurumidl HINTS "${GURUMDDS_ROOT}" PATH_SUFFIXES tool bin REQUIRED)
find_path(GURUMDDS_INCLUDE_DIR gurumdds/dds.h HINTS "${GURUMDDS_ROOT}" PATH_SUFFIXES include REQUIRED)
find_library(GURUMDDS_LIBRARY gurumdds HINTS "${GURUMDDS_ROOT}" PATH_SUFFIXES lib REQUIRED)
find_path(GURUMDDS_CXX_INCLUDE_DIR gurumdds/dds.hpp HINTS "${GURUMDDS_CXX_ROOT}" PATH_SUFFIXES include REQUIRED)
find_library(GURUMDDS_CXX_LIBRARY NAMES gurumdds_psm_cxx gurumdds_psm_cxxd
HINTS "${GURUMDDS_CXX_ROOT}" PATH_SUFFIXES lib REQUIRED)
set(idl_file "${CMAKE_CURRENT_SOURCE_DIR}/Message.idl")
set(generated_dir "${CMAKE_CURRENT_BINARY_DIR}/generated")
set(type_source "${generated_dir}/MessageTypeSupport.cpp")
set(type_headers "${generated_dir}/Message.hpp" "${generated_dir}/MessageTypeSupport.hpp")
add_custom_command(
OUTPUT "${type_source}" ${type_headers}
COMMAND "${CMAKE_COMMAND}" -E make_directory "${generated_dir}"
COMMAND "${CMAKE_COMMAND}" -E rm -f "${type_source}" ${type_headers}
COMMAND "${GURUMIDL}" cpp "${idl_file}" "${generated_dir}"
DEPENDS "${idl_file}" "${GURUMIDL}"
VERBATIM
)
add_executable(idl_app main.cpp "${type_source}" ${type_headers})
target_include_directories(idl_app PRIVATE
"${generated_dir}" "${GURUMDDS_CXX_INCLUDE_DIR}" "${GURUMDDS_INCLUDE_DIR}"
)
target_link_libraries(idl_app PRIVATE "${GURUMDDS_CXX_LIBRARY}" "${GURUMDDS_LIBRARY}")
target_compile_options(idl_app PRIVATE $<$<CXX_COMPILER_ID:MSVC>:/utf-8>)

빌드 및 실행

CMake 3.18 이상과 C++11 컴파일러가 필요합니다. GURUMDDS_ROOT에는 SDK 설치 경로를, GURUMDDS_CXX_ROOT에는 C++ 바인딩 설치 경로를 지정하세요. 같은 곳에 설치했다면 두 변수에 같은 경로를 사용합니다.

Linux

두 Linux 패키지를 모두 /usr에 설치했다면 두 경로에 /usr를 지정합니다. 소스에서 Release로 빌드한 C++ 바인딩을 사용하려면 cxx에 저장소의 output 디렉터리를 지정합니다. 로더가 공유 라이브러리를 찾지 못하면 해당 디렉터리를 LD_LIBRARY_PATH에 추가합니다.

sdk=/usr
cxx=/usr
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release "-DGURUMDDS_ROOT=$sdk" "-DGURUMDDS_CXX_ROOT=$cxx"
cmake --build build
./build/idl_app

프로그램은 Topic 이름과 등록된 타입 이름을 출력합니다. 실행 전에 SDK에 필요한 라이선스를 설정합니다.

Windows에서 MSVC 사용

MSVC x64용 Release SDK와 C++ 바인딩을 사용합니다. 아래 명령은 Visual Studio 2026과 CMake 4.2 이상을 사용합니다. SDK와 바인딩 경로를 설치한 위치로 바꿉니다. CMake가 C++ 파일을 자동으로 생성합니다.

$sdk = "C:/Program Files/Gurumnet/DDS"
$cxx = "C:/path/to/gurumdds-cxx"
cmake -S . -B build-msvc -G "Visual Studio 18 2026" -A x64 "-DGURUMDDS_ROOT=$sdk" "-DGURUMDDS_CXX_ROOT=$cxx"
cmake --build build-msvc --config Release
$env:PATH = "$sdk/lib;$cxx/lib;$env:PATH"
./build-msvc/Release/idl_app.exe

아래 절차는 두 DLL이 각 설치 경로의 lib 디렉터리에 있는 경우입니다. 다른 곳에 설치했다면 실제 디렉터리를 PATH에 추가합니다.
