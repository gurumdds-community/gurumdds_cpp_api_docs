New(C++17)

GurumDDS C++ Examples 저장소의 예제입니다.

CMake 3.20 이상, C++17 컴파일러, C와 C++ 라이브러리 및 GurumIDL이 포함된 GurumDDS 3.2 SDK가 필요합니다.

소스 커밋은 b551d750d62f입니다.

예제 설명
Hello World 타입이 지정된 sample을 한 개 보냅니다. Subscriber가 Received HelloWorld와 payload를 출력합니다.
Keyed sample Key로 instance를 등록하고 조회합니다. Subscriber가 선택한 user_id의 sample을 출력합니다.
DataReader listener 콜백으로 sample을 받습니다. Listener가 Received HelloWorld와 payload를 출력합니다.
ContentFilteredTopic user_id로 필터링합니다. Subscriber가 선택한 ID의 sample을 출력합니다.
XML에서 QoS profile 읽기 XML profile을 읽습니다. 프로그램이 기본 QoS와 profile QoS 값을 비교해 출력합니다.
Lifespan Sample이 만료되기 전과 후의 take 결과를 비교합니다. 만료된 sample은 take 결과에서 사라집니다.
Deadline Deadline보다 길게 쓰기를 멈춥니다. Listener가 Deadline 누락을 알립니다.
TimeBasedFilter 설정한 최소 간격보다 짧게 sample을 보냅니다. Subscriber는 필터를 통과한 sample만 받습니다.
Liveliness 수동 Liveliness 선언을 멈추고 lease 만료 전후의 활성 DataWriter 수를 비교합니다.

cmake --build build
