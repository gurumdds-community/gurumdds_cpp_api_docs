#include <gurumdds/cpp/sub/SampleInfo.hpp>

상세한 설명

template<typename DELEGATE>
class dds::sub::TSampleInfo< DELEGATE >

받은 sample과 그 instance state를 설명합니다.

레코드는 instance 폐기나 마지막 DataWriter의 소실 같은 instance state 변화를 보고할 수 있습니다. 이때 state().instance_state()와 instance_handle()로 이벤트와 instance를 식별하세요. 함께 제공되는 payload에 접근하기 전에 valid()를 확인합니다. 키 기반 Topic에서 DataReader가 아직 instance를 알고 있다면 instance handle을 DataReader의 key_value()에 넘겨 키 필드를 조회할 수 있습니다.

const dds::sub::status::DataState dds::sub::TSampleInfo< DELEGATE >::state ( ) const
inline

sample, 뷰 및 instance state를 가져옵니다.

sample state는 이 DataReader가 sample을 이미 읽었는지 나타냅니다. view state는 DataReader가 이 instance의 현재 세대에 접근한 적이 있는지 나타냅니다. instance state는 instance가 활성 상태인지, 폐기됐는지, DataWriter가 없는지 나타냅니다.

반환값
이 sample과 함께 보고된 sample, 뷰 및 instance state
