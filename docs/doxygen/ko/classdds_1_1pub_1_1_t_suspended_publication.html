일시 중단된 게시에 대한 Publisher 범위 관리

같은 Publisher에 속한 DataWriter들의 갱신 작업을 이 범위로 묶으세요. 객체를 생성하면 C 라이브러리에 발행 일시 중단을 요청합니다. resume()을 성공적으로 호출하면 일시 중단이 끝납니다. 범위 객체를 소멸시킬 때도 발행 재개를 시도합니다. 시점과 버퍼링 동작은 네이티브 Publisher가 결정합니다.

이 객체가 소멸할 때 같은 Publisher의 데이터 발행을 재개하려고 시도합니다.

애플리케이션이 스코프를 종료하기 전에 기본 라이브러리에서 보고한 오류를 처리해야 하는 경우 resume() 를 명시적으로 사용합니다.

Publisher에 대한 일시 중지를 종료합니다.

기본 델리게이트는 첫번째 성공적인 재개를 기록한다. 이 개체에 대한 추가 호출은 C 라이브러리를 호출하지 않고 반환된다.
