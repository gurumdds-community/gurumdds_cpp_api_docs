dds::sub::DataReader< T, DELEGATE >::Selector 클래스

#include <gurumdds/cpp/sub/TDataReader.hpp>

상세한 설명

template<typename T, template< typename Q > class DELEGATE>
class dds::sub::DataReader< T, DELEGATE >::Selector

상태, instance, 개수를 기준으로 sample을 선택합니다.

새로운 선택자는 nil instance handle로 시작하고, 모든 상태 마스크가 사용되며, 명시적인 sample 제한이 없습니다. 해당 instance에만 레코드를 선택하도록 instance handle을 설정합니다. 선택자는 DataReader::default_filter_state()와 독립적으로 자체 상태 마스크를 저장합니다.

read()나 take()를 호출하기 전에 선택자의 max_samples()로 sample 한도를 설정합니다. loan을 반환하는 오버로드와 반복자를 받는 오버로드에 모두 적용합니다. 순방향 반복자 오버로드는 선택자의 한도를 사용하므로 반환할 레코드를 모두 담을 공간이 필요합니다.
