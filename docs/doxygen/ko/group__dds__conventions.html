사용 규칙

Entity handle. handle을 복사하면 같은 Entity를 공유합니다. dds::core::null은 빈 handle입니다. 공통 연산은 dds::core::Reference 에서 확인하세요.

데이터와 메타데이터. 읽기와 꺼내기는 payload 없이 instance 상태 변경을 알릴 수 있습니다. sample.data()에 접근하기 전에 sample.info().valid()를 확인하세요. 반복자나 원소 참조를 쓰는 동안 dds::sub::LoanedSamples 를 유지하세요.

QoS와 오류. 각 QoS 정책의 기본값과 적용 대상을 확인하세요. C 오류 코드를 변환하는 연산은 DDS 예외를 던질 수 있습니다. 반환값과 실패 조건은 각 연산의 설명에 있습니다.

Namespace별 공개 헤더

전체 API를 사용하려면 <gurumdds/dds.hpp>를 포함하세요. 소스 파일에서 쓰는 타입만 포함할 때는 아래 공개 헤더를 사용하세요.

Namespace 주요 헤더

dds::domain <gurumdds/cpp/domain/DomainParticipant.hpp>
dds::topic <gurumdds/cpp/topic/Topic.hpp>, <gurumdds/cpp/topic/ContentFilteredTopic.hpp>

작업별 타입 찾기

작업 타입과 가이드
Entity 생성 Domain, Publication, Subscription
Sample 선택 및 보관 dds::sub::DataReader<T>, dds::sub::LoanedSamples, sample 수신과 선택
전달 정책 설정 QoS 정책 요약 와 DataWriter와 DataReader가 데이터를 교환하지 못할 때 진단하기

복사본이 공유하는 대상

복사 대상 결과
Duration 또는 History 같은 개별 QoS 정책 독립된 값입니다. 복사본을 수정해도 원본 값은 그대로입니다.
DataReader 또는 DataWriter 같은 Entity를 가리키는 handle입니다. 어느 handle에서든 Entity의 변경을 확인할 수 있습니다.
LoanedSamples 같은 레코드와 loan을 공유합니다. 마지막 소유자가 loan을 반환합니다.
복사한 객체를 해제한 뒤 남는 것

loan 반환 뒤에도 샘플 데이터를 사용하는 방법은 sample 수신과 선택 를 참조하세요.
