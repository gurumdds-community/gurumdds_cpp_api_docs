GurumDDS C++ API Reference

GurumDDS는 C 라이브러리 위에 DDS C++ Platform-Specific Model을 구현합니다. 애플리케이션은 타입을 지정한 Topic, DataWriter, DataReader로 sample을 주고받습니다. 전체 API는 <gurumdds/dds.hpp>를, 개별 API는 각 레퍼런스에 표시된 설치 헤더를 포함하세요.

이 API는 C++11을 요구합니다. New 예제는 C++17이 필요합니다.

API 모듈

  • Domain. domain에 참여하고 DomainParticipant와 발견된 endpoint를 조회합니다.
  • Topic. Topic 이름을 데이터 타입에 연결하고 content filter를 설정합니다.
  • Publication. Publisher와 DataWriter를 만들고 sample을 발행하며 instance를 관리합니다.
  • Subscription. Subscriber와 DataReader를 만들고 sample을 선택하며 데이터와 메타데이터에 접근합니다.
  • Core. Entity handle, 시간, 조건, QoS, 예외를 다룹니다.

사용 규칙

handle, sample, QoS, 오류에 대한 설명은 사용 규칙 항목을 참조하세요.
