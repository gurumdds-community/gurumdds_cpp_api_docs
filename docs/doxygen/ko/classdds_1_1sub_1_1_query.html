dds::sub::Query 클래스
API 모듈 » Subscription

#include <gurumdds/cpp/sub/Query.hpp>

상세한 설명

DataReader<T>, 쿼리 표현식 및 표현식 매개변수를 저장합니다.

이 릴리스에서 기본 선택자는 Query 개체를 평가하지 않습니다. 표현식 기반 선택에 대해 ContentFilteredTopic을 사용하십시오.
