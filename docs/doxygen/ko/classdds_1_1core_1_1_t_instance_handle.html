template<typename DELEGATE>
class dds::core::TInstanceHandle< DELEGATE >

DDS 엔터티 또는 데이터 instance를 식별합니다.

nil() 로 instance의 부재를 나타냅니다. 그것을 제공한 Entity에 대한 작업에 handle을 전달합니다.
