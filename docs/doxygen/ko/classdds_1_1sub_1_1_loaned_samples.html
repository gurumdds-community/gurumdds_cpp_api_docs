template<typename T, typename TInfo, template< typename Q, typename W > class DELEGATE>
class dds::sub::LoanedSamples< T, TInfo, DELEGATE >

수신된 sample을 보관하고 미들웨어 loan을 관리합니다.

기본 구현 객체는 C++ sample 레코드를 컬렉션 저장 공간에 생성합니다. 미들웨어 loan을 반환하는 데 필요한 네이티브 시퀀스와 DataReader의 구현 객체도 보관합니다. 컬렉션을 복사하면 레코드와 loan을 공유합니다. 마지막 소유자가 loan을 반환하고 네이티브 시퀀스를 해제합니다.

반복자나 원소 참조를 사용하는 동안 이를 소유하는 컬렉션을 유지하세요. 컬렉션이 해제된 후에도 sample이 필요하면 sample을 값으로 복사하세요. 레코드에 payload 없이 메타데이터만 들어 있을 수 있으므로 sample.data()를 사용하기 전에 sample.info().valid()를 확인합니다.

DataReader에서 얻은 C API의 sample과 메타데이터 시퀀스를 감쌉니다.

컬렉션은 sample 기록을 실체화하고 구현 객체가 파괴될 때 네이티브 loan을 반환합니다.
