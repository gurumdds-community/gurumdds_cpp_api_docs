dds::pub::DataWriter<T>

#include <gurumdds/cpp/pub/DataWriter.hpp>

상세한 설명

데이터 타입이 지정된 Topic에 sample을 쓰고 instance를 관리합니다.

DataWriter는 같은 domain의 Publisher를 통해 입력된 하나의 Topic에 대해 발행합니다. 기본 구현 객체는 Publisher 및 Topic handle의 사본을 유지합니다.

keyed Topic에서는, 각각의 다른 키가 instance를 식별합니다. 그 키로 sample을 작성하거나, 키를 등록하고 나중에 쓰기를 위해 반환된 instance handle을 다시 사용합니다.
