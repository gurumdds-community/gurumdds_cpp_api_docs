dds::topic::ContentFilteredTopic<T>

#include <gurumdds/cpp/topic/ContentFilteredTopic.hpp>

필터 식을 평가하여 기존 Topic에서 sample을 선택합니다. 더 자세히 ...

상세한 설명

필터 식을 평가하여 기존 Topic에서 sample을 선택합니다.

필터링된 설명을 DataReader에게 전달합니다. DataWriter는 원래 이름과 데이터 타입으로 기본 Topic에 대해 계속해서 발행합니다. 예를 들어, 필터 식 userId > 5 는 userId 필드가 5 보다 큰 sample을 선택합니다.

ContentFilteredTopic은 생성할 때 넘긴 Topic<T> 객체를 그대로 참조합니다. ContentFilteredTopic을 사용하는 동안 그 Topic<T> 객체를 유지하세요.

표현식 위치 지정자에 바인딩된 값을 대체합니다

각 위치 지정자에 대한 값을 제공한다. 첫번째 문자열은 %0, 두번째 문자열은 %1 등등을 제공한다. 이 설명에서 기존의 DataReader는 C 라이브러리가 그것들을 받아들이고 나서 업데이트된 매개변수를 사용한다. 표현식 자체는 동일하게 남아 있다.

매개변수
[입력]parameters새로운 표현식 매개변수
예외
dds::core::ExceptionC 라이브러리가 바인딩을 번역하는 오류를 반환합니다.
