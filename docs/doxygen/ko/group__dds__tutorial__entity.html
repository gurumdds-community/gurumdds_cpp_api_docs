Entity handle과 오류 처리
Programming Tutorials

애플리케이션의 여러 부분에서 같은 DDS Entity를 쓸 때는 handle을 복사하세요. 비어 있을 수 있는 handle은 사용 전에 확인하세요. 애플리케이션이 오류를 처리할 수 있는 호출 지점에서 DDS 예외를 잡으세요.

객체 완성 프로그램에서는 아래 코드에 앞서 Publisher와 Topic을 사용해 writer를 만듭니다.

Entity handle 공유하기

두 handle은 같은 DataWriter를 가리킵니다. 복사본의 스코프가 끝나도 원래 handle로 DataWriter를 쓸 수 있습니다.

{
const auto writer_alias = writer;
require(writer_alias == writer, "Copied handle refers to a different writer");
}
require(not writer.is_nil(), "Releasing a copy affected the original");

Entity handle이 비어 있는지 확인

나중에 채울 DataWriter handle은 dds::core::null로 초기화하세요. Entity의 메서드를 호출하기 전에 is_nil()로 handle이 비어 있는지 확인합니다.

dds::pub::DataWriter<T> optional_writer(dds::core::null);
require(optional_writer.is_nil(), "Empty writer handle is not nil");
optional_writer = writer;
require(not optional_writer.is_nil(), "Assigned writer handle is nil");

DDS 예외를 타입별로 처리하기

호출한 연산에 명시된 예외 타입을 처리합니다. 예제는 짧은 기간에서 더 긴 기간을 뺄 때 발생하는 dds::core::InvalidDataError를 처리합니다.

try
{
const auto elapsed = dds::core::Duration::from_millisecs(20);
const auto budget = dds::core::Duration::from_millisecs(10);
const auto remaining = budget - elapsed;
(void)remaining;
}
catch (const dds::core::InvalidDataError&)
{
std::cout << "Caught a negative duration\n";
return;
}
