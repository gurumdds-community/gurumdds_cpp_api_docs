template<typename D>
class dds::core::policy::TReaderDataLifecycle< D >

DataReader가 처분된 instance와 기록되지 않은 instance sample을 정리할 때 설정

두 지연은 instance가 해당 DataReader 상태에 들어갈 때 시작됩니다. 지연이 0인 경우 즉시 정리를 수행할 수 있으며, 무한 지연을 사용하면 해당 상태에서 자동 정리를 비활성화합니다.

독립형 정책은 no-writers 지연을 무한대로, 처리된 지연을 0으로 초기화합니다. DataReader에 처리된 sample의 자동 청소를 비활성화하는 정책이 필요하면 NoAutoPurgeDisposedSamples() 를 사용합니다.
