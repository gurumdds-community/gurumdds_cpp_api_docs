dds::sub::DataReader<T>

#include <gurumdds/cpp/sub/DataReader.hpp>

Topic에서 지정된 타입의 sample을 수신합니다. 더 자세히 ...

상세한 설명

Topic에서 지정된 타입의 sample을 수신합니다.

DataReader는 sample, 뷰, instance state 마스크를 적용해 로컬 history에서 sample을 선택합니다. read()는 반환한 sample을 history에 남겨 두고 읽음 상태로 표시합니다. take()는 반환한 sample을 history에서 제거합니다. payload가 없는 instance state 알림에도 메타데이터가 있습니다. sample.data()를 사용하기 전에 sample.info().valid()를 확인하세요. payload가 유효하지 않으면 sample의 메타데이터로 instance state를 확인하거나 handle을 얻을 수 있습니다.

일상적인 액세스를 위해 DataReader의 기본 필터를 사용합니다. select()와 함께 Selector 를 생성하여 특정 선택에 대한 instance, 상태 마스크 및 레코드 제한을 설정합니다.

레코드를 남기기 read() DataReader<T> 기본 상태 필터를 사용합니다.
레코드 제거 take() DataReader<T> 기본 상태 필터를 사용합니다.
한 번의 수신 범위 제한 select().max_samples(n).take() Selector에 상태, instance, 개수를 설정합니다.

기본 상태 필터와 일치하는 sample을 읽습니다

DataReader는 sample을 보존하고 읽음 상태로 표시합니다. 이후 호출에서 읽지 않은 sample만 선택하면 그 레코드들은 제외됩니다. 반복자나 원소 참조를 사용하는 동안 컬렉션을 유지하고, payload에 접근하기 전에 SampleInfo::valid()를 확인하세요.

반환값
일치하는 데이터가 없거나, 네이티브 시퀀스 할당에 실패하거나, 네이티브 작업에서 오류가 반환되는 경우 일치하는 레코드 또는 비어 있는 컬렉션
