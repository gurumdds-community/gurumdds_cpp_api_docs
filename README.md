# GurumDDS C++ API Reference

This repository contains the generated GurumDDS C++ API Reference in English and Korean.

After cloning, open `docs/index.html` in a browser to choose Doxygen or Poxy. The language selector, search assets, diagrams, and fonts are included in `docs/`.

When updating the reference, copy the complete `doxygen/` and `poxy/` directories into `docs/`. Keep the directory structure for relative links and language switching.
